RichContent в админке

Настройка типов rich content, структура данных, использование в форме и API.

Что такое RichContent

RichContent — это типизированный массив блоков контента. В модели поле обычно описывается как RichContent[], а в админке редактируется через Input::richContent().

Это удобно для страниц, статей, описаний товаров, лендингов и любых сущностей, где нужно хранить не один HTML-текст, а последовательность блоков: текст, HTML, файл, несколько файлов, цитату или embed.

Модель с RichContent
<?php

namespace App\Model;

use Air\Model\ModelAbstract;
use Air\Type\RichContent;

/**
 * @collection Article
 *
 * @property string $id
 * @property string $title
 * @property RichContent[] $content
 * @property boolean $enabled
 * @property integer $createdAt
 * @property integer $updatedAt
 */
class Article extends ModelAbstract
{
}

Настройка допустимых типов блоков

В конфигурации админки можно указать, какие типы блоков разрешены в элементе RichContent. Это глобальная настройка для admin-модуля.

Параметр передаётся в Config::admin() через аргумент richContent. Под капотом значение попадает в air.admin.rich-content, а элемент формы читает его через текущий config.

config.php
<?php

use Air\Config;
use Air\Type\RichContent;

return Config::defaults(
  project: 'AIR',

  admin: fn() => Config::admin(
    domain: 'admin.*',
    title: 'AirCMS',
    richContent: [
      RichContent::TYPE_TEXT,
      RichContent::TYPE_HTML,
      RichContent::TYPE_FILE,
      RichContent::TYPE_FILES,
      RichContent::TYPE_EMBED,
    ],
  ),
);
Если оставить стандартную конфигурацию Config::admin(), список строится на основе Air\Type\RichContent::getAllTypes(). Если нужен блок цитаты, его можно включить явно через RichContent::TYPE_QUOTE.

Какие типы RichContent есть

ТипКонстантаЧто хранится в valueКогда использовать
textRichContent::TYPE_TEXTСтрокаПростой текстовый блок без сложной HTML-разметки.
htmlRichContent::TYPE_HTMLСтрока HTMLБлок с HTML-разметкой, вставками, таблицами или кастомной вёрсткой.
fileRichContent::TYPE_FILEAir\Type\FileОдна картинка, документ или другой файл.
filesRichContent::TYPE_FILESFile[]Галерея изображений или набор файлов.
quoteRichContent::TYPE_QUOTEAir\Type\QuoteЦитата, отзыв, выделенный текстовый блок.
embedRichContent::TYPE_EMBEDСтрокаВстраиваемый код или iframe: видео, карта, внешний виджет.

Использование в форме админки

Все файловые блоки внутри RichContent тоже работают через Air\Type\File. То есть если редактор добавляет картинку в rich content, она сохраняется как объект File и дальше может использоваться в API, UI или sitemap.

Many controller с RichContent
<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Form\Form;
use Air\Form\Input;
use App\Model\Article as ArticleModel;

class Article extends Many
{
  protected function getModelClass(): string
  {
    return ArticleModel::class;
  }

  protected function getForm($model = null): Form
  {
    return new Form(data: $model, elements: [
      'General' => [
        Input::text('title'),
        Input::url('url'),
        Input::checkbox('enabled'),
      ],
      'Content' => [
        Input::richContent('content'),
      ],
    ]);
  }
}

Как отдавать RichContent в API

После чтения модели поле content уже будет массивом объектов Air\Type\RichContent. Для API обычно делают отдельный mapper, который преобразует разные типы блоков в удобный JSON.

Map для RichContent
<?php

namespace App\Context\Article\Map;

use Air\Map;
use Air\Type\File;
use Air\Type\RichContent;

class Article
{
  public static function content(array $content): array
  {
    return array_map(function (RichContent $item): array {
      return match ($item->getType()) {
        RichContent::TYPE_FILE => [
          'type' => 'file',
          'value' => Map::single($item->getValue(), [
            'src' => fn(File $file): string => $file->getSrc(),
            'thumbnail' => fn(File $file): string => $file->getThumbnail(),
          ]),
        ],
        RichContent::TYPE_FILES => [
          'type' => 'files',
          'value' => array_map(
            fn(File $file): array => Map::single($file, [
              'src' => fn(File $file): string => $file->getSrc(),
              'thumbnail' => fn(File $file): string => $file->getThumbnail(),
            ]),
            $item->getValue()
          ),
        ],
        default => [
          'type' => $item->getType(),
          'value' => $item->getValue(),
        ],
      };
    }, $content);
  }
}
