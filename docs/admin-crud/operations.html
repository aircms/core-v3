Copy, Position, Export, Select и Printable

Эта страница описывает встроенные действия CRUD-контроллера Many: копирование записей, копирование в другой язык, сортировку по позиции, CSV-экспорт, режим выбора записей и печатное представление таблицы.

Что это за возможности

Many подключает набор trait-ов для типовых действий над коллекцией. Эти действия работают поверх модели, таблицы, фильтров, router-а админки и текущих условий выборки.

ВозможностьЧто делаетКогда использовать
copy()Создаёт копию записи без id.Дублирование товаров, страниц, шаблонов, настроек.
localizedCopy()Создаёт копию записи для другого языка и пытается перелинковать связанные модели по url + language.Мультиязычные записи через обычное поле language.
position()Показывает drag-and-drop список и сохраняет поле position.Категории, меню, баннеры, блоки страниц.
export()Формирует CSV-файл по колонкам из getExportHeader().Заказы, пользователи, товары, заявки, отчёты.
select()Открывает таблицу в режиме выбора записи.Modal/iframe сценарии, где нужно выбрать объект.
print()Рисует печатное представление таблицы.Накладные, списки, отчёты для печати.

Копирование записей

copy()

Сигнатура
public function copy(string $id): void

Метод загружает запись через fetchOne(['id' => $id]), получает raw-данные через getData(), удаляет id, создаёт новую модель и сохраняет её.

Если у модели есть поле enabled, копия создаётся выключенной. После сохранения вызывается hook didCopied($oldRecord, $newRecord).

Добавить copy в контекстные действия
<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Crud\Controller\MultipleHelper\Accessor\Control;

class Product extends Many
{
  protected function getControls(): array
  {
    return [
      Control::view(),
      Control::manage(),
      Control::copy(),
      Control::enabled(),
    ];
  }
}
Hook после копирования
protected function didCopied(
  ModelAbstract $oldRecord,
  ModelAbstract $newRecord
): void {
  $newRecord->url = $oldRecord->url . '-copy-' . time();
  $newRecord->title = $oldRecord->title . ' copy';
  $newRecord->save();
}

Копирование с учётом языка

localizedCopy()

Сигнатура
public function localizedCopy(string $id, Language $language): void

Метод используется, когда модель имеет обычное поле language. AirCMS создаёт копию записи для указанного языка.

Если у копируемой записи есть связи на другие модели, и эти связанные модели тоже имеют поле language, AirCMS пытается найти соответствующую запись на новом языке по связке url + language и подставить её в копию.

Модель, которая поддерживает языковые копии
/**
 * @collection Page
 *
 * @property string $id
 * @property string $title
 * @property string $url
 * @property PageCategory $category
 * @property \Air\Crud\Model\Language $language
 * @property boolean $enabled
 */
class Page extends ModelAbstract
{
}
Контекстное действие localized copy
protected function getControls(): array
{
  return [
    Control::view(),
    Control::manage(),
    Control::localizedCopy(),
    Control::enabled(),
  ];
}
Важно: это не специальный флаг на поле модели. Это работа с отдельными записями, у которых есть поле language.

Управление позицией

Position включается автоматически, если модель имеет поле position. Экран сортировки загружает записи с учётом текущих условий getConditions(), сортирует их по position и после drag-and-drop сохраняет новый порядок.

getPositioning()

Сигнатура
protected function getPositioning(): string|false

Возвращает поле, которое будет показано как подпись в списке сортировки. По умолчанию это title, если у модели есть position и title.

Модель с position
/**
 * @collection ProductCategory
 *
 * @property string $id
 * @property string $title
 * @property string $url
 * @property integer $position
 * @property boolean $enabled
 */
class ProductCategory extends ModelAbstract
{
}
Кастомная подпись
protected function getPositioning(): string|false
{
  return 'name';
}

position()

Сигнатура
public function position()

Action, который открывает экран сортировки и сохраняет порядок при POST-запросе.

Добавить действие сортировки в действия списка
use Air\Crud\Controller\MultipleHelper\Accessor\HeaderButton;
use Air\Type\FaIcon;

protected function getHeaderButtons(): array
{
  return [
    HeaderButton::item(
      url: ['action' => 'position'],
      icon: FaIcon::ICON_SORT,
      title: 'Sort records'
    ),
  ];
}

Export

Export отдаёт CSV. Чтобы включить экспорт, controller должен вернуть набор колонок в getExportHeader().

getExportFileName()

Сигнатура
protected function getExportFileName(): string

Возвращает базовое имя CSV-файла.

protected function getExportFileName(): string
{
  return 'orders_' . date('Y_m_d');
}

getExportHeader()

Сигнатура
protected function getExportHeader(): ?array

Описывает колонки CSV. Можно использовать те же accessor-классы, что и для таблицы.

use Air\Crud\Controller\MultipleHelper\Accessor\Header;

protected function getExportHeader(): ?array
{
  return [
    Header::text('Title', by: 'title'),
    Header::bool('Enabled', by: 'enabled'),
    Header::dateTime('Created', by: 'createdAt'),
    Header::source('Category', function (Product $product) {
      return $product->category?->title;
    }),
  ];
}

getExportData()

Сигнатура
protected function getExportData(): array|CursorAbstract

Возвращает набор данных для экспорта. По умолчанию используются текущие условия и сортировка.

protected function getExportData(): array|CursorAbstract
{
  return Order::fetchAll(
    [
      ...$this->getConditions(),
      'status' => Order::STATUS_PAID,
    ],
    ['createdAt' => -1]
  );
}

export()

Сигнатура
public function export(): string

Формирует CSV, выставляет headers ответа и возвращает строку CSV.

Select и Printable

select()

Сигнатура
public function select(): void

Открывает таблицу в режиме выбора. Во View передаётся isSelectControl. Это удобно для modal/iframe сценариев.

getPrintableTitle()

Сигнатура
protected function getPrintableTitle(): string

Возвращает заголовок печатной страницы.

protected function getPrintableTitle(): string
{
  return 'Orders report: ' . date('d.m.Y');
}

getPrintableHeader()

Сигнатура
protected function getPrintableHeader(): ?array

Возвращает колонки для печати. По умолчанию используется getHeader().

print()

Сигнатура
public function print(): void

Рисует печатное представление таблицы через script table/printable.

Практический пример

<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Crud\Controller\MultipleHelper\Accessor\Control;
use Air\Crud\Controller\MultipleHelper\Accessor\Header;
use Air\Crud\Controller\MultipleHelper\Accessor\HeaderButton;
use Air\Type\FaIcon;

class Product extends Many
{
  protected function getHeader(): array
  {
    return [
      Header::image(),
      Header::text('Title', by: 'title'),
      Header::bool('Enabled', by: 'enabled'),
      Header::dateTime('Created', by: 'createdAt'),
    ];
  }

  protected function getControls(): array
  {
    return [
      Control::view(),
      Control::manage(),
      Control::copy(),
      Control::localizedCopy(),
      Control::enabled(),
    ];
  }

  protected function getHeaderButtons(): array
  {
    return [
      HeaderButton::item(
        url: ['action' => 'position'],
        icon: FaIcon::ICON_SORT,
        title: 'Sort'
      ),
      HeaderButton::item(
        url: ['action' => 'export'],
        icon: FaIcon::ICON_FILE_EXPORT,
        title: 'Export'
      ),
      HeaderButton::item(
        url: ['action' => 'print'],
        icon: FaIcon::ICON_PRINT,
        title: 'Print'
      ),
    ];
  }
}
