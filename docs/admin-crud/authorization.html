Авторизация

Админка защищается через AuthCrud. Single и Many наследуют эту проверку.

Настройки

Root-доступ и настройки admin-модуля лучше брать из env-переменных.

config.php
<?php

use Air\Config;
use Air\Crud\Nav\Nav;
use Air\Type\FaIcon;

return Config::defaults(
  project: 'AIR',
  admin: fn() => Config::admin(
    domain: 'admin.*',
    title: 'AirCMS',
    nav: [
      Nav::item('Content', FaIcon::ICON_FILE_LINES, items: [
        Nav::item('Articles', controller: 'article'),
      ]),
    ],
  ),
);
Если project: AIR, env namespace проекта — AIR_.... Например: AIR_ADMIN_AUTH_ROOT_LOGIN.

Кастомная проверка прав

Базовый admin controller
<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Guard\Guard;
use RuntimeException;

abstract class AppMany extends Many
{
  public function init(): void
  {
    parent::init();

    Guard::ensure(
      $this->canAccessSection(),
      new RuntimeException('Access denied')
    );
  }

  protected function canAccessSection(): bool
  {
    return true;
  }
}
