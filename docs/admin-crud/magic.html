Magic и переводы в админке

Magic — это набор помощников для заполнения и перевода текстовых полей в админке. Он работает в формах manage, использует структуру модели и настройки AI/translation-провайдеров.

Что такое Magic

В Many подключён trait Magic. Он анализирует metadata модели и строит структуру полей, которые можно автоматически заполнить из текста статьи или файла.

Кнопка Do magic появляется в форме редактирования, если у модели есть поддерживаемые поля и в админке включён OpenAI или DeepSeek.

Важно: Magic не сохраняет запись сам. Он подставляет значения в поля формы, а пользователь проверяет и сохраняет форму обычным способом.

Как строится структура данных

По умолчанию Magic умеет работать с полями title, subTitle, description, meta, richContent, content. Если таких полей нет, структура не будет создана.

getStructure()

Сигнатура
protected function getStructure(): ?array

Возвращает JSON-структуру, которую AI должен заполнить.

/**
 * @collection Article
 *
 * @property string $id
 * @property string $title
 * @property string $subTitle
 * @property string $description
 * @property \Air\Type\Meta $meta
 * @property \Air\Type\RichContent[] $richContent
 * @property boolean $enabled
 */
class Article extends ModelAbstract
{
}

getPrompt()

Сигнатура
protected function getPrompt(): string

Собирает системный prompt для AI: задачу, правила ответа и JSON-структуру.

OpenAI и DeepSeek

Сигнатура

Проверяет, подключён ли settings-раздел OpenAI и включены ли настройки OpenAI.

Сигнатура
protected function isDeepSeekEnabled(): bool

Проверяет, подключён ли settings-раздел DeepSeek и включены ли настройки DeepSeek.

Сигнатура

Принимает текст статьи или описание, отправляет его в DeepSeek и возвращает структурированный массив.

Перевод текстовых данных в инпутах

В админке есть механизм text assistance. Он добавляет контекстное меню к обычным текстовым полям, textarea и tiny/rich text-элементам. Через это меню можно перевести или улучшить значение поля.

Поддерживаются Google Translate, DeepL и DeepSeek.

GoogleTranslate::phrase()

Сигнатура
public function phrase(): array

Берёт phrase и language из запроса, переводит текст и возвращает ['translation' => ...].

Deepl::phrase()

Сигнатура
public function phrase(): array

Работает аналогично Google Translate, но использует DeepL provider.

DeepSeek::phrase()

Сигнатура
public function phrase(string $phrase, Language $language): array

Просит DeepSeek перевести phrase на язык $language и вернуть JSON с ключом translation.

DeepSeek::ask()

Сигнатура
public function ask(
  string $prompt,
  ?string $preData = null,
  ?string $value = null,
  ?string $name = null,
  ?Language $language = null,
): array

Используется для режима Help DeepSeek: можно передать текущее значение поля, имя поля и данные всей формы, чтобы AI предложил более корректный текст.

Как это использовать в форме

В PHP не нужно писать специальный код для кнопок перевода. Достаточно подключить settings-пункты и использовать обычные текстовые элементы формы.

<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Form\Form;
use Air\Form\Input;

class Article extends Many
{
  protected function getForm($model = null): Form
  {
    return new Form(elements: [
      Input::text('title'),
      Input::textarea('description'),
      Input::tiny('content'),
      Input::meta('meta'),
      Input::richContent('richContent'),
    ]);
  }
}

Реальные сценарии

Импорт статьи из текста

Администратор вставляет текст, Magic заполняет title, description, meta и richContent.

Перевод title

Администратор открывает контекстное меню инпута и выбирает Google Translate, DeepL или DeepSeek.

Помощь с description

DeepSeek получает текущее значение и данные всей формы, затем предлагает улучшенный вариант.

SEO meta

Magic может предложить короткие meta title и meta description по содержимому страницы.
