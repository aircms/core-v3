Admin UI helpers

Admin UI helpers — это набор глобальных функций для быстрой сборки HTML-интерфейсов внутри админки AirCMS: карточки, таблицы, кнопки, бейджи, сетка, изображения, свойства и готовая обёртка страницы.

Что это такое

Файлы Air/Crud/View/Ui/* содержат небольшие функции, которые возвращают HTML-строки. Они удобны в кастомных admin actions, в ячейках таблиц, в модальных окнах, в preview-блоках и в страницах, где не хочется создавать отдельный .phtml view.

Важно: эти функции подключаются для admin-модуля через Config::admin(), где в air.require добавляется vendor/aircms/core-v3/src/Air/Crud/View/Ui/ui.php. В обычном API/UI-модуле их надо подключать отдельно, если они там нужны.
Admin config автоматически подключает UI helpers
use Air\Config;

return Config::defaults(
  project: 'AIR',
  admin: fn() => Config::admin(
    domain: 'admin.*',
    title: 'AirCMS',
  ),
);

Справочник функций

Ниже перечислены функции из Air/Crud/View/Ui/*. Каждый helper возвращает HTML-строку, поэтому его можно использовать в ячейке таблицы, в custom action, в callback-е, в модальном окне или в странице без отдельного view-файла.

Страница, заголовок и контейнеры

page($title = null, $content = null, $icon = null, $buttons = null): string

Собирает полную admin-страницу из sticky-заголовка и контентной области.

Пример
return page(
  title: 'Orders dashboard',
  icon: FaIcon::ICON_BRIEFCASE,
  buttons: btn('Refresh', ['action' => 'dashboard'], style: SECONDARY),
  content: card('Content goes here')
);

title($title, $icon = null, $buttons = null): string

Рисует верхний заголовок страницы. Полезно, когда страницу нужно собрать вручную.

Пример
echo title(
  title: 'Import products',
  icon: FaIcon::ICON_UPLOAD,
  buttons: btn('Back', ['controller' => 'product'])
);

contents($content): string

Оборачивает основной контент страницы в стандартный контейнер с прокруткой.

Пример
echo contents([
  card('Import result', title: 'Result'),
  card('Errors', title: 'Validation')
]);

card($content = null, $title = null, $containerClass = null, $titleClass = null, $bodyClass = null, $contentClass = null, string $size = SPACE3, string $color = SURFACE, bool $noLine = false, $data = null): string

Создаёт карточку в стиле админки. Используйте для блоков статистики, деталей записи, групп свойств и кастомных страниц.

Пример
return card(
  title: 'Order summary',
  content: properties([
    'Status' => badge('Paid', SUCCESS),
    'Total' => '$120.00',
  ])
);

Кнопки, ссылки и модальные действия

btn($content, $url = '#', $class = null, $confirm = null, $style = PRIMARY, $size = SM, $icon = null, $attr = [], $data = [], $type = null): string

Рисует кнопку или ссылку-кнопку. Подходит для actions, custom pages, quick links.

Пример
return btn(
  content: 'Sync all',
  url: ['action' => 'syncAll'],
  confirm: 'Sync all products?',
  style: WARNING,
  icon: FaIcon::ICON_ROTATE
);

lnk($content, string $url, $confirm = null, $color = PRIMARY, $size = MD, $isBlank = false): string

Рисует текстовую ссылку. Если URL содержит @, превращает его в mailto; если не начинается с http — в tel.

Пример
echo lnk('support@example.com', 'support@example.com');
echo lnk('+40700000000', '+40700000000');
echo lnk('Open website', 'https://aircms.pro', isBlank: true);

modal(string $url, $content): string

Создаёт кликабельный элемент, который открывает URL внутри embed-модального окна.

Пример
return modal(
  url: $this->getRouter()->assemble(['action' => 'preview'], ['id' => $model->id]),
  content: badge('Preview', INFO)
);

html(string $url, $content, ?string $title = ''): string

Создаёт кликабельный элемент, который загружает HTML через AJAX в модальное окно.

Пример
return html(
  url: $this->getRouter()->assemble(['action' => 'details'], ['id' => $order->id]),
  content: 'Details',
  title: 'Order details'
);

Labels, badges and status output

badge($content, $color = PRIMARY, $url = null): string

Рисует badge. Удобно для статусов, количества, флагов, быстрых ссылок.

Пример
echo badge('Active', SUCCESS);
echo badge('Failed', DANGER);
echo badge('Open order', INFO, $orderUrl);

badgeCond($condition, $label, $url = null, $trueColor = PRIMARY, $falseColor = DARK): string

Рисует положительный/отрицательный badge на основе условия.

Пример
echo badgeCond($user->emailConfirmed, 'email confirmed');
echo badgeCond(count($order->items), 'items', $orderUrl);

label(string $label, ?string $class = null, $color = PRIMARY, $size = MD): string

Рисует простой текстовый label с цветом и размером.

Пример
echo label('VIP customer', color: WARNING, size: LG);
echo label('Archived', class: 'text-decoration-line-through', color: SECONDARY);

Flex and grid helpers

vertical($content, $class = true, $space = SPACE1, $justify = START, $align = START): string

Вертикальная flex-группа. Полезно для preview-карточек и ячеек таблиц.

Пример
return vertical([
  label($product->title),
  badge($product->enabled ? 'Enabled' : 'Disabled'),
]);

horizontal($content, $class = null, $space = SPACE1, $justify = START, $align = START, $wrap = true): string

Горизонтальная flex-группа. Используйте для набора badges, изображений, кнопок.

Пример
return horizontal(
  content: [image($product->image), label($product->title)],
  align: CENTER,
  space: SPACE2,
  wrap: false
);

row($content = null, $class = null, $attr = null, $bgImage = null, $gt = SPACE1): string

Bootstrap row helper. Используйте для сетки карточек.

Пример
return row([
  col(card('128', title: 'Orders'), md: 4),
  col(card('$9 200', title: 'Revenue'), md: 4),
  col(card('17', title: 'Refunds'), md: 4),
]);

col($content = null, $class = null, $attr = null, $bgImage = null, ?int $col = null, ?int $md = null, ?int $lg = null, ?int $xl = null, ?int $xxl = null): string

Bootstrap col helper. Используется вместе с row().

Пример
echo col(
  content: card('Block content'),
  md: 6,
  xl: 4
);

Images and files

image(File|string|null $image = null, bool $preview = true, $size = SM): ?string

Рисует preview изображения или файла. Если передан Air\Type\File, берёт src, thumbnail, alt, title из объекта.

Пример
return image($product->image);

return image(
  image: $product->image,
  preview: true,
  size: SM
);

images(?array $images = null, bool $preview = true): ?string

Рисует набор изображений через horizontal().

Пример
return images($product->images);
return images($order->attachments, preview: false);

modelPreview(ModelAbstract $model): string

Автоматически собирает короткий preview модели: изображение из image/images и название из title/name.

Пример
return modelPreview($order->user);
return modelPreview($product);

Таблицы, свойства, JSON и даты

tbl(array $body = [], ?array $data = null, $footer = null): string

Создаёт HTML-таблицу. В $body ключ — заголовок колонки, значение — callback или статическое значение.

Пример
return tbl(
  body: [
    'Product' => fn(Product $product) => modelPreview($product),
    'Price' => fn(Product $product) => badge('$' . $product->price, SUCCESS),
    'Status' => fn(Product $product) => badgeCond($product->enabled, 'enabled'),
  ],
  data: Product::fetchAll([], ['createdAt' => -1], count: 20)
);

properties(array $keyValues = []): string

Рисует список key/value свойств в сетке. Удобно для карточки деталей.

Пример
return properties([
  'ID' => $order->id,
  'Customer' => modelPreview($order->user),
  'Status' => badge($order->status, INFO),
  'Created' => format($order->createdAt),
]);

json($json): string

Рисует JSON в textarea с data-атрибутом json-viewer. Полезно для debug/details страниц.

Пример
return json($payment->payload);
return json($request->getParams());

duration(int $seconds, bool $showDays = true, bool $showHours = true, bool $showMinutes = true, bool $showSeconds = true): string

Форматирует длительность.

Пример
echo duration(3661);
echo duration(time() - $queue->createdAt, showSeconds: false);

isToday(int $timestamp): bool

Проверяет, относится ли timestamp к сегодняшнему дню.

Пример
if (isToday($order->createdAt)) {
  echo badge('Today', INFO);
}

isTomorrow(int $timestamp): bool

Проверяет, относится ли timestamp к завтрашнему дню.

Пример
echo isTomorrow($delivery->date) ? badge('Tomorrow') : format($delivery->date);

format(?int $timestamp = null, string $format = 'Y/m/d H:i'): string

Форматирует timestamp через PHP date().

Пример
echo format($order->createdAt);
echo format($order->createdAt, 'd.m.Y H:i');

Константы и CSS helpers

getFontSize(string $size = MD): ?string

Возвращает CSS-класс размера: fs-12, fs-16, fs-20.

Пример
echo span('Small note', getFontSize(SM));
echo span('Large title', getFontSize(LG));

getTextColor(?string $color = null): ?string

Возвращает класс цвета текста, например text-primary.

Пример
echo span('Warning', getTextColor(WARNING));

getBgColor(?string $color = null): ?string

Возвращает класс background color, например body-bg-surface.

Пример
echo div('Block', getBgColor(SURFACE));

Полноценная страница без View

Если страница небольшая, можно не создавать View/Scripts/*.phtml. В admin controller можно отключить autorender и вернуть HTML, собранный через page(), card(), tbl(), properties() и другие helpers.

Admin controller без .phtml View
<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\AuthCrud;
use Air\Type\FaIcon;
use App\Model\Order;

class Dashboard extends AuthCrud
{
  public function index(): string
  {
    $this->getView()->setAutoRender(false);

    $orders = Order::fetchAll([], ['createdAt' => -1], count: 10);

    return page(
      title: 'Dashboard',
      icon: FaIcon::ICON_CHART_LINE,
      buttons: btn('Refresh', ['controller' => 'dashboard'], style: SECONDARY),
      content: vertical([
        row([
          col(card(Order::count(), title: 'Orders'), md: 4),
          col(card(Order::count(['status' => Order::STATUS_PAID]), title: 'Paid'), md: 4),
          col(card(Order::count(['status' => Order::STATUS_FAILED]), title: 'Failed'), md: 4),
        ]),
        card(
          title: 'Latest orders',
          content: tbl(
            body: [
              'User' => fn(Order $order) => modelPreview($order->user),
              'Status' => fn(Order $order) => badge($order->status, INFO),
              'Created' => fn(Order $order) => format($order->createdAt),
              'Actions' => fn(Order $order) => html(
                $this->getRouter()->assemble(
                  ['action' => 'details'],
                  ['order' => $order->id]
                ),
                'Details',
                'Order details'
              ),
            ],
            data: $orders
          )
        ),
      ], space: SPACE3)
    );
  }

  public function details(Order $order): string
  {
    $this->getView()->setAutoRender(false);

    return page(
      title: 'Order details',
      icon: FaIcon::ICON_RECEIPT,
      content: card(
        title: 'Main information',
        content: properties([
          'ID' => $order->id,
          'User' => modelPreview($order->user),
          'Status' => badge($order->status, INFO),
          'Created' => format($order->createdAt),
          'Payload' => json($order->payload),
        ])
      )
    );
  }
}
Когда так делать: dashboard, debug/details, report, импорт, небольшие служебные страницы. Для больших шаблонов с большим количеством HTML лучше использовать обычный view script.
