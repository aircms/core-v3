Admin & CRUD

Админка AirCMS строится вокруг модели и CRUD-контроллера. Контроллер описывает таблицу, фильтры, формы, действия строки и действия списка.

Связка модели и контроллера

Обычно имя admin-контроллера совпадает с именем модели. Контроллер article работает с моделью App\Model\Article.

app/Module/Admin/Controller/Article.php
<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Form\Form;
use Air\Form\Input;

class Article extends Many
{
  protected function getForm($model = null): ?Form
  {
    return new Form($model, elements: [
      Input::text('title'),
      Input::text('url'),
      Input::textarea('description', allowNull: true),
      Input::checkbox('enabled'),
    ]);
  }
}
app/Model/Article.php
<?php

namespace App\Model;

use Air\Model\ModelAbstract;

/**
 * @collection Article
 *
 * @property string $id
 * @property string $title
 * @property string $url
 * @property string $description
 * @property boolean $enabled
 * @property integer $position
 * @property integer $createdAt
 * @property integer $updatedAt
 */
class Article extends ModelAbstract
{
}

Single и Many

КлассДля чего нуженКейс
Air\Crud\Controller\SingleОдна логическая запись.Главная страница, footer, settings.
Air\Crud\Controller\ManyКоллекция записей.Articles, Products, Orders, Users.
Используйте Many для коллекций записей. Старый базовый контроллер для многих записей не используйте в новой документации и новых примерах.

Актуальный стиль описания админки

В новых примерах не используются docblock-модификаторы и ручные конфигурационные массивы. Актуальный стиль — возвращать массив, собранный через статические методы helper-классов: Header::..., Filter::..., Control::..., HeaderButton::..., Nav::item().

Современный подход
<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Crud\Controller\MultipleHelper\Accessor\Control;
use Air\Crud\Controller\MultipleHelper\Accessor\Filter;
use Air\Crud\Controller\MultipleHelper\Accessor\Header;
use Air\Form\Form;
use Air\Form\Input;
use Air\Type\FaIcon;

class Product extends Many
{
  protected function getHeader(): array
  {
    return [
      Header::image(),
      Header::title(),
      Header::longtext(by: 'description'),
      Header::enabled(),
      Header::createdAndUpdated(),
    ];
  }

  protected function getFilter(): array
  {
    return [
      Filter::search(['id', 'title', 'url']),
      Filter::enabled(),
      Filter::createdAt(),
    ];
  }

  protected function getControls(): array
  {
    return [
      Control::view(),
      Control::manage(),
      Control::copy(),
      Control::enabled(),
      Control::separator(),
      Control::runAndReload(
        ['action' => 'sync'],
        FaIcon::ICON_ROTATE,
        'Sync',
        'Sync this product?'
      ),
    ];
  }

  protected function getForm($model = null): ?Form
  {
    return new Form($model, elements: [
      Input::text('title'),
      Input::text('url'),
      Input::textarea('description', allowNull: true),
      Input::storage('image', allowNull: true),
      Input::checkbox('enabled'),
    ]);
  }
}
Namespace MultipleHelper остался в ядре для совместимости helper-классов. В документации и новых проектах базовым CRUD-контроллером для коллекций остаётся Many.

Генератор форм

Для типовых CRUD-разделов можно не описывать всю форму вручную. Используйте генератор форм, если поля модели следуют стандартным именам AirCMS: title, url, description, image, enabled, meta и т.д.

Структура сложного CRUD

Для маленького раздела достаточно одного controller-файла. Для сложного раздела удобно разнести таблицу, форму, действия и кастомные страницы по trait-классам.

Пример структуры
app/Module/Admin/Controller/Product/
  Controller.php
  Table.php
  Form.php
  Controls.php
  Actions.php
  View.php
Controller.php
<?php

namespace App\Module\Admin\Controller\Product;

use Air\Crud\Controller\Many;

class Controller extends Many
{
  use Table;
  use Form;
  use Controls;
  use Actions;
}

Реальные кейсы

Каталог товаров

Many, фильтр по категории, превью изображения, action синхронизации, массовое редактирование.

Настройки главной страницы

Single, отдельная запись на язык, SEO meta, баннеры и блоки.

Заказы

Кастомные ячейки со статусом, фильтры по датам, контекстное действие смены статуса.

Модерация

Своя страница details и действия approve/reject через Control::runAndReload().
