Request & Response

Работа с входящим запросом и исходящим ответом: параметры, JSON body, headers, files, status code, response headers и практические сценарии использования.

Что такое Request & Response

Air\Core\Request и Air\Core\Response — это два базовых объекта, через которые контроллеры, плагины и error controller работают с входящим запросом и исходящим ответом.

Request

Содержит GET, POST, JSON body, headers, files, URI, домен, IP, user-agent и HTTP method.

Response

Содержит status code, status message, headers и body, которые AirCMS отправит клиенту после выполнения controller action.

Где использовать: в controller action, init(), plugins, error controller и worker-командах. В обычном API чаще всего читают данные через $this->getParams() или action injection, но для headers, files и meta-информации нужен именно Request.

Доступ из контроллера

В любом контроллере можно получить request и response через методы базового Air\Core\Controller.

Request/Response в action
<?php

namespace App\Module\Api\Controller;

use Air\Core\Controller;

class Profile extends Controller
{
  public function index(): array
  {
    $request = $this->getRequest();
    $response = $this->getResponse();

    $response->setHeader('content-type', 'application/json');

    return [
      'ip' => $request->getIp(),
      'method' => $request->getMethod(),
      'uri' => $request->getUriRequest(),
    ];
  }
}

Чтение параметров запроса

AirCMS разделяет параметры на GET, POST и общий набор params. Для JSON-запроса с заголовком content-type: application/json тело запроса декодируется в POST params и общий params.

getParam()

Сигнатура
public function getParam(string $name, $default = null, array $filters = []): mixed

Читает параметр из общего набора params. Обычно это самый удобный вариант для API, потому что туда попадают параметры запроса, формы и JSON body.

Чтение общего параметра
$name = $this->getRequest()->getParam('name');
$page = $this->getRequest()->getParam('page', 1);

return [
  'name' => $name,
  'page' => (int)$page,
];

getParams()

Сигнатура
public function getParams(): array

Возвращает все параметры запроса. Этот метод удобно использовать вместе с формами в API.

Передача всех params в форму
$form = new ContactForm();

if (!$form->isValid($this->getParams())) {
  $this->getResponse()->setStatusCode(400);

  return [
    'errors' => $form->getErrorFields(),
  ];
}

return [
  'data' => $form->getValues(),
];

getGet() и getGetAll()

Сигнатура
public function getGet(string $key, $default = null, array $filters = [])
public function getGetAll(): array

Используются, когда нужно явно читать query string: фильтры списка, пагинацию, сортировку.

GET-параметры списка
$page = $this->getRequest()->getGet('page', 1);
$sort = $this->getRequest()->getGet('sort', 'createdAt');
$filters = $this->getRequest()->getGetAll();

return [
  'page' => (int)$page,
  'sort' => $sort,
  'filters' => $filters,
];

getPost() и getPostAll()

Сигнатура
public function getPost(string $key, $default = null, array $filters = []): mixed
public function getPostAll(): array

Используются, когда нужно явно работать с POST body. Для JSON body AirCMS тоже заполняет POST params, если запрос пришёл с application/json.

POST-данные
$email = $this->getRequest()->getPost('email');
$password = $this->getRequest()->getPost('password');

return AuthService::signIn($email, $password);

filters

Сигнатура
public function getParam(string $name, $default = null, array $filters = []): mixed

В методы чтения можно передавать фильтры. AirCMS создаёт объект фильтра и применяет его к значению.

Фильтрация параметра
use Air\Filter\Lowercase;
use Air\Filter\Trim;

$email = $this->getRequest()->getParam('email', null, [
  Trim::class,
  Lowercase::class,
]);

Headers, method, URI и meta-информация

Эти методы полезны для API-auth, подписи запросов, CORS, language header, webhook-ов и логирования.

getHeader()

Сигнатура
public function getHeader(string $key): ?string
public function getHeaders(): array
public function getXHeaders(): array

Headers внутри Request хранятся в нижнем регистре, поэтому читать их нужно так же: authorization, language, x-signature.

Чтение headers
$language = $this->getRequest()->getHeader('language');
$token = $this->getRequest()->getHeader('authorization');
$signature = $this->getRequest()->getHeader('x-signature');

return [
  'language' => $language,
  'token' => $token,
  'signature' => $signature,
];

HTTP method

Сигнатура
public function isGet(): bool
public function isPost(): bool
public function isPut(): bool
public function isDelete(): bool
public function getMethod(): ?string

Проверка method нужна для endpoints, которые принимают несколько вариантов запроса, или для security checks.

Ограничение метода
if (!$this->getRequest()->isPost()) {
  $this->getResponse()->setStatusCode(405);

  return [
    'error' => 'Only POST requests are allowed',
  ];
}

URI, domain, scheme, IP

Сигнатура
public function getUri(): string
public function getUriRequest(): string
public function getUriParams(): string
public function getDomain(): string
public function getScheme(): string
public function getPort(): int
public function getIp(): string
public function getUserAgent(): string

Эти методы полезны для логов, analytics, signature validation, webhook debugging и построения абсолютных ссылок.

Логирование запроса
Air\Log::info('api-request', [
  'uri' => $this->getRequest()->getUriRequest(),
  'query' => $this->getRequest()->getUriParams(),
  'ip' => $this->getRequest()->getIp(),
  'ua' => $this->getRequest()->getUserAgent(),
]);

AJAX и iframe

Сигнатура
public function isAjax(): bool
public function isIframe(): ?bool

isAjax() определяется по X-Requested-With: XMLHttpRequest. isIframe() определяется по Sec-Fetch-Dest: iframe.

Отдельный ответ для AJAX
if ($this->getRequest()->isAjax()) {
  return [
    'html' => $this->getView()->render('partials/card.phtml'),
  ];
}

Файлы в Request

При загрузке файлов AirCMS преобразует данные из $_FILES в объекты Air\Core\Request\File. Это временный объект uploaded-file, не тот же самый объект, что Air\Type\File из Storage.

getFile()

Сигнатура
public function getFile(string $fileKey): ?Air\Core\Request\File

Возвращает один загруженный файл по имени поля.

Один файл
$file = $this->getRequest()->getFile('image');

if (!$file || $file->getError()) {
  $this->getResponse()->setStatusCode(400);

  return [
    'error' => 'Image is required',
  ];
}

$uploaded = Air\Storage::uploadFiles('/articles', [
  'image' => $file->toArray(),
]);

getMultipleFile() и getFiles()

Сигнатура
public function getMultipleFile(string $fileKey): ?Air\Core\Request\File
public function getFiles(): array

Используются для полей с несколькими файлами и для debug всех uploaded files.

Несколько файлов
$images = $this->getRequest()->getMultipleFile('images');
$allFiles = $this->getRequest()->getFiles();

return [
  'images' => $images,
  'all' => array_keys($allFiles),
];

Air\Core\Request\File

Сигнатура
public function getName(): ?string
public function getType(): ?string
public function getTmpName(): ?string
public function getError(): int
public function getSize(): int
public function toArray(): array

Это объект временного загруженного файла. Через него удобно проверять mime, размер и temporary path до передачи файла в storage.

Проверка размера
$file = $this->getRequest()->getFile('document');

if ($file && $file->getSize() > 10 * 1024 * 1024) {
  $this->getResponse()->setStatusCode(413);

  return [
    'error' => 'File is too large',
  ];
}

Response

Response управляет тем, что будет отправлено клиенту. Обычно action просто возвращает массив или строку, а AirCMS сам положит результат в response body. Но status code и headers часто нужно выставлять вручную.

setStatusCode()

Сигнатура
public function setStatusCode(int $statusCode): void
public function getStatusCode(): int

Используется для ошибок формы, not found, forbidden, created, accepted и любых API-статусов.

201 Created
$this->getResponse()->setStatusCode(201);

return [
  'created' => true,
  'id' => $article->id,
];

setHeader(), setHeaders(), addHeaders()

Сигнатура
public function setHeader(string $key, string $value): void
public function setHeaders(array $headers): void
public function addHeaders(array $headers): void

Заголовки ответа нужны для JSON API, CORS, file download, cache control и security headers.

Headers ответа
$this->getResponse()->setHeader('content-type', 'application/json');
$this->getResponse()->addHeaders([
  'x-api-version' => '1',
  'cache-control' => 'no-store',
]);

setBody()

Сигнатура
public function setBody($body): void
public function getBody(): mixed

Обычно body устанавливается автоматически из return value action-а. Ручное управление полезно в plugins, error controllers или нестандартных ответах.

Пустой ответ
$this->getResponse()->setStatusCode(204);
$this->getResponse()->setBody(null);

return null;

Request & Response в plugins и error controller

Plugin получает request, response и router напрямую в аргументах. Это удобно для CORS, авторизации, подписи запроса и maintenance mode.

Plugin с headers ответа
<?php

namespace App\Module\Api\Plugin;

use Air\Core\Plugin;
use Air\Core\Request;
use Air\Core\Response;
use Air\Core\Router;

class Cors extends Plugin
{
  public function preRun(Request $request, Response $response, Router $router): bool
  {
    $response->setHeader('access-control-allow-origin', '*');
    $response->setHeader('access-control-allow-methods', 'GET, POST, PUT, DELETE, OPTIONS');

    return true;
  }
}
ErrorController меняет Response
<?php

namespace App\Module\Api\Controller;

use Air\Core\ErrorController;
use Air\Form\Exception\Validation;

class Error extends ErrorController
{
  public function index(): array
  {
    $exception = $this->getException();

    if ($exception instanceof Validation) {
      $this->getResponse()->setStatusCode(400);

      return [
        'errors' => $exception->getForm()->getErrorFields(),
      ];
    }

    $this->getResponse()->setStatusCode(500);

    return [
      'error' => 'Server error',
    ];
  }
}
