Встроенные уведомления

Встроенные уведомления AirCMS: email, Telegram, SMS, очереди, шаблоны и прямые provider-клиенты.

Что входит во встроенные уведомления

AirCMS содержит готовый слой для отправки уведомлений через email, Telegram и SMS. Этот слой можно использовать двумя способами: через очередь или через немедленную отправку.

Email

SMTP или Resend, шаблоны, очередь, отложенная отправка, debug output.

Telegram

Отправка сообщений в один или несколько chat id через Bot API.

SMS

Единый фасад Air\Sms, который использует SMS.to или GatewayAPI.

Очереди

Сообщения сохраняются в queue-модели и обрабатываются worker-ами через consume().

Базовый workflow

Обычный production-поток выглядит так:

  1. Код проекта вызывает Email::add(), Telegram::add() или Sms::add().
  2. AirCMS создаёт запись в queue-модели со статусом new.
  3. CLI worker вызывает consume().
  4. Сообщение отправляется через выбранный gateway.
  5. Очередь получает статус success или fail, а технический ответ записывается в debugOutput.
<?php

use Air\Email;
use Air\Sms;
use Air\Telegram;
use Air\Crud\Model\EmailTemplate;
use Air\Crud\Model\SmsTemplate;
use Air\Crud\Model\TelegramTemplate;

Email::add(
  toAddress: 'client@example.com',
  toName: 'Client',
  template: EmailTemplate::tpl('order-created'),
  vars: ['order' => '#1001']
);

Telegram::add(
  template: TelegramTemplate::tpl('new-order'),
  vars: ['order' => '#1001']
);

Sms::add(
  toAddress: '+40700000000',
  template: SmsTemplate::tpl('order-code'),
  vars: ['code' => '123456']
);

Очередь и немедленная отправка

ПодходКак использоватьКогда подходит
Через очередьadd(...), addPlain(...), затем worker вызывает consume()Основной production-вариант: email, SMS, Telegram, массовые уведомления.
Немедленно через фасадadd(..., force: true) или addPlain(..., force: true)Когда нужно создать queue-запись и сразу попытаться отправить сообщение.
Напрямую через providernew Smsto(...)->send(...), new Gatewayapi(...)->send(...)Когда нужно обойти queue-модели и вызвать внешний SMS-gateway напрямую.
