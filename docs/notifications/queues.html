Очереди и workers

Очереди уведомлений в AirCMS: статусы, consume-методы, отложенная отправка и запуск worker-ов.

Что такое очередь уведомлений

Очередь — это коллекция сообщений, которые ещё не отправлены или уже были обработаны. Для каждого канала есть своя queue-модель:

  • Air\Crud\Model\EmailQueue
  • Air\Crud\Model\TelegramQueue
  • Air\Crud\Model\SmsQueue

Очередь удобна тем, что пользовательский HTTP-запрос не ждёт реальную отправку email/SMS/Telegram. Сообщение быстро сохраняется, а отправка выполняется отдельным CLI worker-ом.

Статусы сообщений

МодельСтатусыДополнительные поля
EmailQueuenew, in-progress, success, failwhen, inProgress, debugOutput, attachments
TelegramQueuenew, success, failwhen, inProgress, debugOutput, botToken, chatIds
SmsQueuenew, success, failwhen, debugOutput, toAddress, message

Методы обработки очереди

Email::consume()

Берёт одно email-сообщение со статусом new, помечает его как inProgress и отправляет через gateway из EmailSettings.

Сигнатура
public static function consume(): bool

Worker для email

<?php

namespace App\Module\Cli\Controller;

use Air\Core\Worker;
use Air\Email;

class Notification extends Worker
{
  protected function email(): ?bool
  {
    return Email::consume();
  }
}

Telegram::consume()

Берёт одно Telegram-сообщение из очереди и отправляет его через Telegram Bot API.

Сигнатура
public static function consume(): bool

Worker для Telegram

<?php

namespace App\Module\Cli\Controller;

use Air\Core\Worker;
use Air\Telegram;

class Notification extends Worker
{
  protected function telegram(): ?bool
  {
    return Telegram::consume();
  }
}

Sms::consume()

Берёт пачку SMS-сообщений из очереди и отправляет их через gateway, указанный в SmsSettings.

Сигнатура
public static function consume(int $chunk = 50): bool

Worker для SMS

<?php

namespace App\Module\Cli\Controller;

use Air\Core\Worker;
use Air\Sms;

class Notification extends Worker
{
  protected function sms(): ?bool
  {
    return Sms::consume(chunk: 50);
  }
}

Отложенная отправка

Параметр when задаёт timestamp, после которого сообщение можно отправлять. Worker обрабатывает только записи, у которых when <= time().

<?php

use Air\Email;
use Air\Crud\Model\EmailTemplate;

Email::add(
  toAddress: 'client@example.com',
  toName: 'Client',
  template: EmailTemplate::tpl('reminder'),
  vars: ['name' => 'Client'],
  when: strtotime('+1 hour')
);

Запуск через Supervisor

[program:aircms-email]
user = www-data
command = php www/index.php route=notification/email
directory = /var/www/project
autostart = true
autorestart = true
stdout_logfile = /var/log/supervisor/aircms-email.log
