File object

Air\Type\File — typed object, которым AirCMS представляет файл внутри моделей, форм, API и админки. Если поле модели описано как File или File[], данные из базы будут автоматически преобразованы в объект File.

Поля объекта File

ПолеТипОписание
sizeintРазмер файла в байтах.
mimestringMIME type файла. Для папки может быть directory.
pathstringПуть к файлу внутри storage.
timeintВремя создания/изменения файла.
srcstringОсновной путь к файлу.
thumbnailstringПуть к thumbnail.
titlestringЗаголовок файла.
altstringAlt-текст изображения.
dimsarrayРазмеры изображения: width и height.

Использование в модели

<?php

namespace App\Model;

use Air\Model\ModelAbstract;
use Air\Type\File;

/**
 * @collection Product
 *
 * @property string $id
 * @property string $title
 * @property File $image
 * @property File[] $gallery
 */
class Product extends ModelAbstract
{
}

После чтения модели поля image и элементы массива gallery будут объектами Air\Type\File.

<?php

$product = Product::one($id);

$imageUrl = $product->image?->getSrc();
$thumbnail = $product->image?->getThumbnail();

Методы File

getSize()

Сигнатура
public function getSize(): int

Возвращает размер файла в байтах.

<?php

$size = $product->image->getSize();

getMime()

Сигнатура
public function getMime(): string

Возвращает MIME type файла.

<?php

if ($product->image->getMime() === 'image/png') {
  // PNG image
}

getPath()

Сигнатура
public function getPath(): string

Возвращает storage path файла.

<?php

$path = $product->image->getPath();

getTime()

Сигнатура
public function getTime(): int

Возвращает timestamp файла.

<?php

$uploadedAt = date('Y-m-d H:i:s', $product->image->getTime());

getTitle()

Сигнатура
public function getTitle(): string

Возвращает title файла.

<?php

$title = $product->image->getTitle();

getAlt()

Сигнатура
public function getAlt(): string

Возвращает alt-текст файла.

<?php

$alt = $product->image->getAlt();

getDims()

Сигнатура
public function getDims(): array

Возвращает массив с размерами изображения.

<?php

$dims = $product->image->getDims();

$width = $dims['width'] ?? 0;
$height = $dims['height'] ?? 0;

getThumbnail()

Сигнатура
public function getThumbnail(): string

Возвращает полный URL thumbnail. Если thumbnail уже начинается с http, он возвращается как есть. Иначе к нему добавляется storage URL из конфига.

<?php

return [
  'thumbnail' => $product->image?->getThumbnail(),
];

getSrc()

Сигнатура
public function getSrc(?int $width = null, ?int $height = null, ?int $quality = null, ?string $format = null): string

Возвращает полный URL файла. Дополнительно умеет сформировать URL модифицированного изображения: с шириной, высотой, качеством и форматом.

<?php

$original = $product->image->getSrc();
$preview = $product->image->getSrc(width: 480, height: 360);
$webp = $product->image->getSrc(width: 1200, quality: 85, format: File::WEBP);

getFilename()

Сигнатура
public function getFilename(): string

Возвращает имя файла из src.

<?php

$filename = $product->image->getFilename();

getSrcContent()

Сигнатура
public function getSrcContent(): string|false

Читает содержимое файла по URL getSrc(). Используй аккуратно: метод делает сетевое чтение и может быть тяжёлым для больших файлов.

<?php

$content = $product->image->getSrcContent();

getBase64Content()

Сигнатура
public function getBase64Content(): string

Возвращает base64-контент файла.

<?php

$base64 = $product->image->getBase64Content();

isImage()

Сигнатура
public function isImage(): bool

Проверяет, содержит ли MIME type строку image.

<?php

if ($product->image?->isImage()) {
  $src = $product->image->getSrc(width: 800);
}

remove()

Сигнатура
public function remove(): bool

Удаляет файл или папку в storage. Если mime === directory, вызывается удаление папки, иначе удаление файла.

<?php

if ($product->image) {
  $product->image->remove();
  $product->image = null;
  $product->save();
}

fromArray()

Сигнатура
public static function fromArray(?array $file): self

Создаёт объект File из массива. Полезно в mapper-ах, legacy данных или при ручной нормализации.

<?php

$file = Air\Type\File::fromArray($rawFile);
