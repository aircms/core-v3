Файлы в админке

Вся работа с файлами в админке AirCMS завязана на объект Air\Type\File. Когда в модели поле описано как File или File[], admin form может отрисовать storage input, а сохранённое значение будет преобразовано в нужный typed object.

Поля модели для файлов

Одиночный файл описывается как File, несколько файлов — как File[].

<?php

use Air\Model\ModelAbstract;
use Air\Type\File;

/**
 * @collection Article
 *
 * @property string $id
 * @property string $title
 * @property File $cover
 * @property File[] $gallery
 */
class Article extends ModelAbstract
{
}

Форма в админке

Для файловых полей в админке используется storage element. Через Input::storage() можно быстро создать элемент, который открывает storage UI, выбирает файл и сохраняет его структуру в модель.

<?php

namespace App\Module\Admin\Controller;

use Air\Crud\Controller\Many;
use Air\Form\Form;
use Air\Form\Input;

class Article extends Many
{
  protected function getForm($model = null): Form
  {
    return new Form(elements: [
      Input::text('title'),
      Input::storage('cover'),
      Input::storage('gallery', multiple: true),
    ]);
  }
}
В админке storage input работает не с бинарным файлом напрямую, а со структурой файла, которую потом ORM превращает в Air\Type\File.

Через класс элемента

Если нужно больше контроля, можно создать Air\Form\Element\Storage напрямую.

<?php

use Air\Form\Element\Storage;

$image = new Storage('cover');
$image->setMultiple(false);

$gallery = new Storage('gallery');
$gallery->setMultiple(true);

Вывод файлов в API

В API обычно не нужно отдавать весь объект File. Лучше явно собрать нужные URL и metadata через Map.

<?php

use Air\Map;
use Air\Type\File;

return Map::single($article, [
  'id',
  'title',
  'cover' => fn($article) => $article->cover ? [
    'src' => $article->cover->getSrc(width: 1200, format: File::WEBP),
    'thumbnail' => $article->cover->getThumbnail(),
    'alt' => $article->cover->getAlt(),
  ] : null,
  'gallery' => fn($article) => Map::multiple(
    $article->gallery ?? [],
    fn(File $file) => [
      'src' => $file->getSrc(width: 1200, format: File::WEBP),
      'preview' => $file->getSrc(width: 420, height: 320, format: File::WEBP),
      'alt' => $file->getAlt(),
    ]
  ),
]);

Кастомная admin-страница с файлами

Файлы можно использовать и на своих admin-страницах без отдельного view-файла: собрать HTML через Admin UI helpers и методы File.

<?php

use function Air\Crud\View\Ui\page;
use function Air\Crud\View\Ui\card;
use function Air\Crud\View\Ui\image;
use function Air\Crud\View\Ui\contents;

public function preview(Article $article): string
{
  return page(
    title: 'Article preview',
    content: contents([
      card(
        title: $article->title,
        content: image(
          src: $article->cover?->getSrc(width: 800),
          title: $article->cover?->getTitle()
        )
      )
    ])
  );
}
