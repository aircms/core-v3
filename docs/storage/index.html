Storage

Storage в AirCMS — это слой работы с файлами, который отделяет backend-проект от физического хранения файлов. Основной проект хранит в моделях только объект Air\Type\File, а загрузка, удаление, создание папок и обработка изображений выполняются через отдельный storage-сервис.

Что такое Storage в AirCMS

В AirCMS файловое хранилище рассматривается как отдельный сервис. Backend-проект обращается к нему через Air\Storage, а в моделях и формах использует объект Air\Type\File. Благодаря этому один и тот же проект может хранить изображения, документы и другие файлы вне основного приложения.

Ключевая идея: модель не хранит бинарные данные файла. В базе сохраняется структура файла: путь, URL, mime-type, размер, thumbnail, размеры изображения и дополнительные поля вроде title и alt.
<?php

/**
 * @collection Product
 *
 * @property string $id
 * @property string $title
 * @property \Air\Type\File $image
 * @property \Air\Type\File[] $gallery
 */
class Product extends \Air\Model\ModelAbstract
{
}

Настройки storage

Storage подключается через секцию air.storage. При использовании Config::defaults() значения берутся из environment variables с namespace проекта.

<?php

use Air\Config;

return Config::defaults(
  project: 'AIR',
  admin: fn() => Config::admin(),
  api: fn() => Config::api(),
);
AIR_FS_URL=https://storage.example.com
AIR_FS_KEY=secret-storage-key

Если project: 'ATWA', то AirCMS будет искать уже ATWA_FS_URL и ATWA_FS_KEY.

Как проходит работа с файлом

1. Загрузка

Файл загружается через storage UI, форму админки или программно через Air\Storage.

2. Ответ storage

Storage возвращает массив с src, thumbnail, mime, size, dims и другими данными.

3. Объект File

AirCMS превращает ответ storage в Air\Type\File и сохраняет его в модель.

4. Использование

В API, UI и админке файл читается через методы объекта File: getSrc(), getThumbnail(), isImage().
