Air\Storage

Air\Storage — фасад для общения с отдельным storage-сервисом. Он отправляет запросы на storage API, передаёт ключ доступа и возвращает объекты Air\Type\File.

Как это работает

Все высокоуровневые методы Air\Storage внутри вызывают storage endpoint-ы. Адрес сервиса и ключ берутся из Front::getInstance()->getConfig()['air']['storage'].

<?php

$storageConfig = Front::getInstance()->getConfig()['air']['storage'];

$url = $storageConfig['url'];
$key = $storageConfig['key'];
Обычно тебе не нужно вручную обращаться к storage API. В проекте достаточно использовать Air\Storage, а в моделях хранить Air\Type\File.

Методы Air\Storage

createFolder()

Сигнатура
public static function createFolder(string $path, string $name, bool $recursive = false, bool $sharding = false): string

Создаёт папку в storage-сервисе и возвращает путь к созданной папке. Параметр sharding добавляет вложенные hash-директории, чтобы не складывать слишком много файлов в одну директорию.

<?php

$path = Air\Storage::createFolder(
  path: '/',
  name: 'products',
  recursive: true
);

deleteFolder()

Сигнатура
public static function deleteFolder(string $path): bool

Удаляет папку в storage-сервисе. Метод возвращает true, если storage подтвердил удаление.

<?php

Air\Storage::deleteFolder('/products/old');

uploadByUrl()

Сигнатура
public static function uploadByUrl(string $path, string $url, bool $sharding = false): Air\Type\File

Загружает файл в storage по внешнему URL и возвращает объект File. Удобно для импортов, парсеров и миграций.

<?php

$file = Air\Storage::uploadByUrl(
  path: '/products',
  url: 'https://example.com/image.jpg',
  sharding: true
);

$product->image = $file;
$product->save();

uploadFiles()

Сигнатура
public static function uploadFiles(string $path, array $files, bool $sharding = false): array

Загружает файлы из $_FILES и возвращает массив объектов File. Этот сценарий полезен для кастомных upload endpoint-ов.

<?php

$files = Air\Storage::uploadFiles(
  path: '/products',
  files: $_FILES['images'],
  sharding: true
);

uploadDatum()

Сигнатура
public static function uploadDatum(string $path, array $datum, bool $sharding = false): array

Загружает набор данных в storage. Метод полезен, когда файл приходит не как обычный upload, а как подготовленная структура данных.

<?php

$files = Air\Storage::uploadDatum('/imports', [
  [
    'type' => 'url',
    'data' => 'https://example.com/a.jpg',
  ],
]);

uploadBase64Datum()

Сигнатура
public static function uploadBase64Datum(string $path, array $datum, bool $sharding = false): array

Загружает массив base64-изображений. AirCMS оборачивает каждую строку в структуру {type: base64, data: ...} и передаёт её в storage.

<?php

$files = Air\Storage::uploadBase64Datum('/avatars', [
  $this->getParam('avatar'),
]);

$user->avatar = $files[0] ?? null;
$user->save();

info()

Сигнатура
public static function info(array|string $paths): array|Air\Type\File

Получает информацию о файле или списке файлов из storage и возвращает File либо массив File[].

<?php

$file = Air\Storage::info('/products/image.jpg');

$files = Air\Storage::info([
  '/products/1.jpg',
  '/products/2.jpg',
]);

deleteFile()

Сигнатура
public static function deleteFile(string $path): bool

Удаляет файл по storage path. В большинстве случаев удобнее вызывать $file->remove(), потому что объект сам понимает, файл это или директория.

<?php

Air\Storage::deleteFile('/products/old.jpg');

refactor()

Сигнатура
public static function refactor(Air\Type\File $file, ?int $width = null, ?int $height = null, ?int $quality = null): bool

Физически переобрабатывает изображение через storage-сервис. Метод работает только с изображениями и возвращает false, если файл не является картинкой.

<?php

Air\Storage::refactor(
  file: $product->image,
  width: 1200,
  height: 900,
  quality: 85
);

annotation()

Сигнатура
public static function annotation(string $folder, string $fileName, string $title, string $backColor, string $frontColor): ?Air\Type\File

Создаёт файл-аннотацию через storage-сервис. Это удобно для генерации простых placeholder-изображений, заглушек, preview-картинок.

<?php

$file = Air\Storage::annotation(
  folder: '/placeholders',
  fileName: 'empty-product.png',
  title: 'No image',
  backColor: '#f3f4f6',
  frontColor: '#111827'
);

action()

Сигнатура
public static function action(string $endpoint, ?array $params = []): Air\Http\Response

Низкоуровневый вызов storage endpoint-а. Используй его только если в Air\Storage нет готового метода.

<?php

$response = Air\Storage::action('customEndpoint', [
  'path' => '/products',
]);

isImage()

Сигнатура
public static function isImage(string|array $input): bool

Проверяет, является ли входное значение изображением. Метод умеет работать с base64-строкой и с массивом, похожим на storage-файл.

<?php

if (!Air\Storage::isImage($this->getParam('avatar'))) {
  throw new RuntimeException('Avatar must be an image');
}
