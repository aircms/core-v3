Examples

Практические и нестандартные примеры использования моделей AirCMS.

Полная сущность: статья

Пример модели с scalar-полями, ссылкой на категорию, массивом тегов, typed object и conventions.

app/Model/Article.php
<?php

namespace App\Model;

use Air\Model\ModelAbstract;
use Air\Type\File;
use Air\Type\Meta;

/**
 * @collection Article
 *
 * @property string $id
 * @property string $title
 * @property string $url
 * @property string $description
 * @property Category $category
 * @property Category[] $relatedCategories
 * @property File $image
 * @property Meta $meta
 * @property array $tags
 * @property integer $views
 * @property boolean $enabled
 * @property integer $position
 * @property integer $createdAt
 * @property integer $updatedAt
 */
class Article extends ModelAbstract
{
}

Soft delete через enabled

Чаще всего публичные записи не удаляются физически, а отключаются через enabled. После этого one() и all() перестают их возвращать.

Soft delete
$article = Article::one('old-page');

if ($article) {
  $article->enabled = false;
  $article->save();
}

// Вернёт null, потому что one() добавит enabled = true.
$publicArticle = Article::one('old-page');

// Вернёт запись, потому что fetchOne() не добавляет enabled = true.
$adminArticle = Article::fetchOne('old-page');

Импорт данных

Для импорта лучше готовить массивы данных и использовать batchInsert(). Если данные нужно нормализовать сложнее — создавай модель, вызывай populate(), затем бери getData().

Импорт CSV
$rows = [];

foreach ($itemsFromCsv as $item) {
  $article = new Article();
  $article->populate([
    'title' => trim($item['title']),
    'url' => Air\Slug::generate($item['title']),
    'enabled' => true,
  ]);

  $rows[] = $article->getData();
}

Article::batchInsert($rows);

Обработка большой коллекции

Если коллекция большая, не используй all() без лимита. Для пакетной обработки используй iterate().

Batch processing
Article::iterate(
  function (Article $article, int $batchIndex, int $index): void {
    Article::update($article->id, [
      'views' => 0,
      'updatedAt' => time(),
    ]);
  },
  batchSize: 500,
  cond: ['enabled' => true],
  map: ['id', 'views']
);

Typed object как вложенный DTO

Typed object можно использовать как вложенный DTO: он преобразуется в raw array для хранения и обратно в объект при чтении.

Typed object в API
$article = new Article();
$article->title = 'Landing page';
$article->meta = new Air\Type\Meta([
  'title' => 'Landing page',
  'description' => 'SEO description',
]);
$article->save();

$article = Article::one($article->id);

return [
  'title' => $article->title,
  'meta' => $article->meta->toRaw(),
];

Projection для лёгких API-ответов

Параметр $map позволяет читать только нужные поля. Это полезно для списков, sitemap, меню и быстрых API-методов.

Projection + Map
$articles = Article::all(
  ['enabled' => true],
  ['position' => 1],
  map: ['id', 'title', 'url']
);

return Air\Map::multiple($articles, [
  'id',
  'title',
  'url',
]);

Raw-доступ для админки

В публичном API чаще используются one() и all(). В админке часто нужны fetchOne() и fetchAll(), чтобы видеть disabled-записи.

Admin usage
$article = Article::fetchOne($id);

if (!$article) {
  throw new RuntimeException('Article was not found');
}

$article->enabled = true;
$article->save();
