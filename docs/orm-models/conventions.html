Conventions моделей

Некоторые поля в AirCMS имеют специальное поведение. Если поле существует в metadata модели, ядро и driver могут автоматически использовать его при чтении, сортировке или сохранении.

Выборка по id, _id и url

В MongoDB реальное поле идентификатора называется _id, но в моделях AirCMS обычно используется id. Driver автоматически преобразует условие id в _id.

Если значение id не похоже на MongoDB ObjectId и в модели есть поле url, MongoDB driver пытается искать запись по url. Это удобно для URL-slug-ов.

id / url lookup
// Поиск по MongoDB ObjectId.
$article = Article::one('65f02d1f2d7c9d1011111111');

// Если строка не ObjectId и у модели есть поле url,
// MongoDB driver попробует искать по url.
$article = Article::one('about-us');

// Явный поиск по url.
$article = Article::one(['url' => 'about-us']);
Важно: fallback id → url относится к MongoDB driver-у. В MySQL строка/число передаётся как primary value модели.

@primary

По умолчанию primary-поле — id. Если нужно использовать другое поле, можно указать @primary. Тогда вызовы с scalar condition будут строиться по этому полю.

Primary по url
/**
 * @collection Page
 * @primary url
 *
 * @property string $url
 * @property string $title
 * @property boolean $enabled
 */
class Page extends ModelAbstract
{
}

$page = Page::one('about-us'); // условие будет по primary url

enabled

Если у модели есть поле enabled, методы one(), all(), singleOne(), singleAll() автоматически добавляют условие enabled = true, если ты явно не передал другое значение.

enabled convention
// Автоматически добавит ['enabled' => true].
$articles = Article::all();

// Явно получить отключённые записи.
$disabledArticles = Article::all(['enabled' => false]);

// Получить всё без automatic convention.
$allArticles = Article::fetchAll();

position

Если у модели есть поле position, методы one(), all(), singleOne(), singleAll() автоматически добавляют сортировку position ASC, если сортировка не была указана явно.

position convention
// Автоматически отсортирует по ['position' => 1].
$items = MenuItem::all();

// Явная сортировка имеет приоритет.
$latest = MenuItem::all([], ['createdAt' => -1]);

// Без automatic sort.
$raw = MenuItem::fetchAll();

createdAt и updatedAt

Если поля createdAt и updatedAt описаны как integer, AirCMS может автоматически проставлять UNIX timestamp.

$model->save() существующая записьНе меняется.Обновляется автоматически.
batchInsert() / insert()Заполняется автоматически в driver-е.Заполняется автоматически в driver-е.
update()Не заполняется автоматически.Не заполняется автоматически, если ты сам не передал поле в $data.
createdAt / updatedAt
$article = new Article();
$article->title = 'Новая статья';
$article->save();

echo $article->createdAt;
echo $article->updatedAt;

Article::update($article->id, [
  'title' => 'Обновлено',
  'updatedAt' => time(),
]);

url

Поле url не генерируется автоматически на уровне ModelAbstract. Обычно проект сам формирует slug через Air\Slug или собственную бизнес-логику. Но наличие поля url важно для MongoDB fallback: если поиск по id невозможен как ObjectId, driver может искать по url.

url как slug
use Air\Slug;

$article = new Article();
$article->title = 'About Company';
$article->url = Slug::generate($article->title);
$article->enabled = true;
$article->save();

$article = Article::one('about-company');

one/all vs fetchOne/fetchAll

Методы one() и all() применяют conventions: enabled, language, position. Методы fetchOne() и fetchAll() обращаются к driver-у напрямую и не добавляют эти условия.

Разница методов
// С automatic conventions.
$article = Article::one('about-us');

// Сырой запрос без enabled/language/position.
$article = Article::fetchOne('about-us');

Механизм преобразования данных

Document driver использует metadata поля и преобразует данные при записи и чтении. Это позволяет хранить в базе простые значения, но работать в коде с объектами.

Тип поляПри записиПри чтении
ScalarПриводится через settype().Возвращается scalar нужного типа.
arrayMongoDB хранит массив, MySQL хранит JSON.Возвращается PHP array.
Model referenceСохраняется primary value модели.Возвращается объект связанной модели.
Model reference arrayСохраняется массив primary values.Возвращается массив моделей.
Typed objectСохраняется raw array или JSON.Возвращается объект типа.
Typed object arrayСохраняется массив raw arrays.Возвращается массив typed objects.
