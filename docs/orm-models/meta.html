Meta models

Meta model в AirCMS — это объектное описание модели, построенное из PHPDoc-аннотаций. Через metadata ядро понимает имя коллекции, primary-поле, список свойств, типы данных, enum-значения, связи с другими моделями и typed objects.

Что такое Meta model

Когда модель наследуется от Air\Model\ModelAbstract, AirCMS читает её PHPDoc-блок и строит объект Air\Model\Meta. Это не отдельная таблица и не запись в базе данных. Это runtime-описание модели, которое используется ORM, формами, CRUD-админкой, автоматическим приведением типов и helper-логикой.

Например, из такого класса AirCMS сможет понять, что коллекция называется Article, primary-поле — id, поле category является ссылкой на модель, а поле meta — typed object.

Модель, из которой строится metadata
<?php

namespace App\Model;

use Air\Model\ModelAbstract;
use Air\Type\Meta;

/**
 * @collection Article
 * @primary id
 *
 * @property string $id
 * @property string $title
 * @property string $url
 * @property Category $category
 * @property Category[] $relatedCategories
 * @property Meta $meta
 * @property string $status
 * @property boolean $enabled
 * @property integer $position
 * @property integer $createdAt
 * @property integer $updatedAt
 */
class Article extends ModelAbstract
{
  const string STATUS_DRAFT = 'draft';
  const string STATUS_PUBLISHED = 'published';
}

Как создаётся metadata

Обычно metadata не нужно создавать вручную. Достаточно вызвать Article::meta() или $article->getMeta(). Внутри будет создан объект Air\Model\Meta, который распарсит PHPDoc модели.

Получение metadata через static method
$meta = Article::meta();

$collection = $meta->getCollection();
$primary = $meta->getPrimary();
$properties = $meta->getProperties();
Получение metadata из объекта модели
$article = new Article();
$meta = $article->getMeta();

if ($meta->hasProperty('url')) {
  $article->url = 'about-us';
}
Важно: Air\Model\Meta кеширует результат парсинга внутри процесса. Это значит, что повторные вызовы metadata для той же модели не должны каждый раз заново парсить PHPDoc.

Где это используется

МестоКак используется metadata
ORM driverПонимает collection/table, primary field, список свойств и типы данных.
Document conversionПреобразует raw array из базы в scalar values, model references, typed objects и массивы.
Admin CRUDМожет строить формы, таблицы и элементы интерфейса на основе свойств модели.
Form generatorОпределяет, какой form element подходит для конкретного поля.
API helpersПозволяет строить универсальные map/filter/sort механизмы без ручного списка полей.
Schema reflectionВ MySQL driver-е metadata может использоваться для синхронизации структуры таблиц.

Методы Air\Model\Meta

Ниже каждый метод описан отдельно: сигнатура, назначение и примеры использования.

getCollection()

Сигнатура
public function getCollection(): string

Возвращает имя коллекции или таблицы, указанное через @collection.

Пример
$collection = Article::meta()->getCollection();

// Article

setCollection()

Сигнатура
public function setCollection(string $collection): void

Меняет имя коллекции внутри metadata-объекта. В обычном коде приложения почти не используется. Может быть полезно в тестах, генераторах или нестандартных инструментах.

Пример
$meta = Article::meta();
$meta->setCollection('ArticleArchive');

$collection = $meta->getCollection();

getPrimary()

Сигнатура
public function getPrimary(): string

Возвращает primary-поле модели. Если @primary не указан, AirCMS использует id.

Пример
$primary = Article::meta()->getPrimary();

// id

setPrimary()

Сигнатура
public function setPrimary(string $primary): void

Меняет primary-поле в metadata-объекте. Обычно primary задаётся через @primary, поэтому ручная установка нужна редко.

Пример
$meta = Article::meta();
$meta->setPrimary('url');

$primary = $meta->getPrimary();

getProperties()

Сигнатура
/**
 * @return Air\Model\Meta\Property[]
 */
public function getProperties(): array

Возвращает список свойств модели в виде массива объектов Air\Model\Meta\Property. Удобно использовать, когда нужно пройтись по всем полям модели.

Вывести список полей
foreach (Article::meta()->getProperties() as $property) {
  echo $property->getName() . ': ' . $property->getType() . PHP_EOL;
}

getAssocProperties()

Сигнатура
/**
 * @return array<string, Air\Model\Meta\Property>
 */
public function getAssocProperties(): array

Возвращает свойства как ассоциативный массив, где ключ — имя свойства. Это удобно для быстрых проверок и генераторов.

Получить property по имени без поиска
$properties = Article::meta()->getAssocProperties();

if (isset($properties['title'])) {
  $type = $properties['title']->getType();
}

setProperties()

Сигнатура
public function setProperties(array $fields): void

Заменяет список properties внутри metadata-объекта. В прикладном коде используется редко. Может пригодиться в тестах или специальных инструментах генерации.

Пример
$meta = Article::meta();
$properties = $meta->getProperties();

$meta->setProperties($properties);

getPropertyWithName()

Сигнатура
public function getPropertyWithName(string $name): Air\Model\Meta\Property

Возвращает объект property по имени. Если свойства нет, выбрасывается Air\Model\Meta\Exception\PropertyWasNotFound.

Получить описание поля
$property = Article::meta()->getPropertyWithName('category');

if ($property->isModel()) {
  echo 'category является ссылкой на модель';
}
Безопасная проверка перед чтением
$meta = Article::meta();

if ($meta->hasProperty('seoTitle')) {
  $property = $meta->getPropertyWithName('seoTitle');
}

hasProperty()

Сигнатура
public function hasProperty(string $name): bool

Проверяет, существует ли поле в metadata модели. Это один из самых полезных методов для универсальных фильтров, сортировки, API и admin-инструментов.

Проверка поля перед фильтром
$meta = Article::meta();
$cond = [];

if ($meta->hasProperty('enabled')) {
  $cond['enabled'] = true;
}

$items = Article::fetchAll($cond);

Методы Air\Model\Meta\Property

Объект Property описывает одно поле модели: имя, тип, raw type, массивность, enum, связь с моделью и typed object.

getName()

Сигнатура
public function getName(): string

Возвращает имя поля без символа $.

Пример
$property = Article::meta()->getPropertyWithName('title');
$name = $property->getName();

// title

getType()

Сигнатура
public function getType(): string

Возвращает полный тип поля. Для классов AirCMS пытается подставить namespace из use или текущего namespace модели.

Пример
$property = Article::meta()->getPropertyWithName('meta');
$type = $property->getType();

// Air\Type\Meta

getRawType()

Сигнатура
public function getRawType(): ?string

Возвращает тип без признака массива. Например, для Category[] raw type будет App\Model\Category.

Пример
$property = Article::meta()->getPropertyWithName('relatedCategories');

$type = $property->getType();
$rawType = $property->getRawType();

// type: App\Model\Category[]
// raw type: App\Model\Category

isMultiple()

Сигнатура
public function isMultiple(): ?bool

Показывает, описано ли поле как массив через [].

Пример
$property = Article::meta()->getPropertyWithName('relatedCategories');

if ($property->isMultiple()) {
  echo 'Поле хранит массив значений';
}

isModel()

Сигнатура
public function isModel(): ?bool

Возвращает true, если тип поля является классом, который наследуется от Air\Model\ModelAbstract.

Найти связи с другими моделями
foreach (Article::meta()->getProperties() as $property) {
  if ($property->isModel()) {
    echo $property->getName() . ' -> ' . $property->getRawType() . PHP_EOL;
  }
}

isTypeAbstract()

Сигнатура
public function isTypeAbstract(): bool

Возвращает true, если тип поля является typed object на базе Air\Type\TypeAbstract.

Найти typed objects
foreach (Article::meta()->getProperties() as $property) {
  if ($property->isTypeAbstract()) {
    echo $property->getName() . ' is typed object' . PHP_EOL;
  }
}

isEnum() и getEnum()

Сигнатуры
public function isEnum(): ?bool
public function getEnum(): ?array

Если в модели есть constants с префиксом имени свойства, AirCMS считает поле enum. Например, для поля status constants STATUS_DRAFT и STATUS_PUBLISHED станут enum-options.

Получить enum options
$property = Article::meta()->getPropertyWithName('status');

if ($property->isEnum()) {
  $options = $property->getEnum();
}
Пример результата
[
  'Draft' => 'draft',
  'Published' => 'published',
]
