Methods

Методы моделей сгруппированы по назначению. Каждый метод описан отдельно: сигнатура, что делает и практические примеры.

Методы чтения данных

Эти методы получают одну или несколько записей из базы. Методы без префикса fetch применяют conventions модели.

one()

Сигнатура
public static function one(
  array|string|int $cond = [],
  array $sort = [],
  array $map = []
): static|null

Возвращает одну модель или null. Перед запросом применяет addCond() и addPosition(), поэтому учитывает enabled, language и position, если такие поля есть в модели.

Поиск по id или url
$article = Article::one('65f02d1f2d7c9d1011111111');
$article = Article::one('about-us');
Поиск по условию
$article = Article::one([
  'url' => 'about-us',
]);
Сортировка
$latest = Article::one(
  ['enabled' => true],
  ['createdAt' => -1]
);

fetchOne()

Сигнатура
public static function fetchOne(
  array|string|int $cond = [],
  array $sort = [],
  array $map = []
): static|null

Возвращает одну модель напрямую через driver. Не добавляет automatic conditions enabled и language, и не добавляет default sort по position. Полезно для служебных задач, админки, миграций и случаев, когда нужно получить запись независимо от её статуса.

Получить отключённую запись
$article = Article::fetchOne([
  'url' => 'draft-page',
]);
Projection / map
$article = Article::fetchOne(
  ['url' => 'about-us'],
  [],
  ['id', 'title', 'url']
);

singleOne()

Сигнатура
public static function singleOne(
  array|string|int $cond = [],
  array $sort = [],
  array $map = []
): static|null

То же, что one(), но результат кэшируется внутри одного request через Air\Cache::single(). Это не persistent cache между запросами.

Повторное чтение в рамках одного запроса
$settings = Settings::singleOne();

// Второй вызов с теми же параметрами вернётся из request-cache.
$settingsAgain = Settings::singleOne();

object()

Сигнатура
public static function object(
  array|string|int $cond = [],
  array $sort = [],
  array $map = []
): static|null

Пытается найти запись через one(). Если запись не найдена, возвращает новый пустой объект модели. Удобно для single settings или формы редактирования, где объект нужен всегда.

Settings object
$settings = Settings::object();
$settings->title = $settings->title ?: 'Default title';

fetchObject()

Сигнатура
public static function fetchObject(
  array|string|int $cond = [],
  array $sort = []
): static

Driver-level аналог object(). Если запись найдена — возвращает её, если нет — возвращает пустой объект модели. Не применяет conventions one().

Сырой settings object
$settings = Settings::fetchObject([
  'key' => 'main',
]);

all()

Сигнатура
public static function all(
  array|string|int $cond = [],
  array $sort = [],
  ?int $count = null,
  ?int $offset = null,
  array $map = []
): CursorAbstract|array

Возвращает набор моделей. Применяет automatic conventions: enabled, language, position. Обычно это основной метод для публичных выборок.

Список записей
$articles = Article::all(
  ['category' => $category],
  ['createdAt' => -1],
  20,
  0
);

foreach ($articles as $article) {
  echo $article->title;
}
Projection
$articles = Article::all(
  [],
  ['position' => 1],
  map: ['id', 'title', 'url']
);

fetchAll()

Сигнатура
public static function fetchAll(
  array|string|int $cond = [],
  array $sort = [],
  ?int $count = null,
  ?int $offset = null,
  array $map = []
): CursorAbstract|array

Сырой метод чтения коллекции без automatic conventions. Используется, когда нужно получить все записи, включая disabled или записи на другом языке.

Все записи без enabled filter
$articles = Article::fetchAll([], ['createdAt' => -1]);
Пагинация
$page = 3;
$limit = 20;
$offset = ($page - 1) * $limit;

$articles = Article::fetchAll(
  [],
  ['createdAt' => -1],
  $limit,
  $offset
);

singleAll()

Сигнатура
public static function singleAll(
  array|string|int $cond = [],
  array $sort = [],
  ?int $count = null,
  ?int $offset = null,
  array $map = []
): CursorAbstract|array

То же, что all(), но результат кэшируется внутри одного request через Air\Cache::single(). Полезно для меню, справочников, настроек и повторного чтения одних и тех же данных.

Меню
$items = MenuItem::singleAll([], ['position' => 1]);
$itemsAgain = MenuItem::singleAll([], ['position' => 1]);

quantity()

Сигнатура
public static function quantity(array|string|int $cond = []): int

Возвращает количество записей с применением automatic conventions через addCond(). То есть если у модели есть enabled, по умолчанию будут считаться только включённые записи.

Количество опубликованных записей
$total = Article::quantity();
Количество по категории
$total = Article::quantity([
  'category' => $category,
]);

count()

Сигнатура
public static function count(array|string|int $cond = []): int

Считает записи напрямую через driver. Не применяет conventions. Используй, когда нужно посчитать всё или когда условия уже подготовлены полностью.

Сырой count
$total = Article::count();
$disabled = Article::count(['enabled' => false]);

iterate()

Сигнатура
public static function iterate(
  callable $callback,
  int $batchSize = 1,
  array $cond = [],
  array $map = []
): void

Обходит большую коллекцию батчами. В MongoDB driver использует последовательное чтение по _id, чтобы не загружать всю коллекцию в память.

Обработка батчами
Article::iterate(
  function (Article $article, int $batchIndex, int $index): void {
    echo $article->title;
  },
  batchSize: 100,
  cond: ['enabled' => true],
  map: ['id', 'title']
);

Методы добавления данных

Эти методы создают новые записи. Перед записью данные проходят через модель и document driver, поэтому типы приводятся согласно @property.

insert()

Сигнатура
public static function insert(array $data = []): int

Создаёт одну запись. В MongoDB возвращает количество вставленных записей, в MySQL — id последней вставленной записи. Если в модели есть createdAt и updatedAt типа integer, driver заполнит их автоматически.

Создать запись массивом
Article::insert([
  'title' => 'Новая статья',
  'url' => 'new-article',
  'enabled' => true,
]);

batchInsert()

Сигнатура
public static function batchInsert(array $data = []): int

Создаёт несколько записей за один вызов. Каждая запись проходит через модель, поэтому scalar-типы, model references и typed objects нормализуются перед записью.

Массовое добавление
Article::batchInsert([
  [
    'title' => 'Первая статья',
    'url' => 'first-article',
    'enabled' => true,
  ],
  [
    'title' => 'Вторая статья',
    'url' => 'second-article',
    'enabled' => true,
  ],
]);

Методы записи и обновления данных

Эти методы изменяют существующие записи или сохраняют объект модели.

update()

Сигнатура
public static function update(
  array|string|int $cond = [],
  array $data = []
): int

Обновляет записи, которые подходят под условие. Если условие — строка или число, оно интерпретируется как primary value. Метод не добавляет автоматический updatedAt, если ты не передал его в $data.

Обновить по id
Article::update($articleId, [
  'title' => 'Новое название',
  'updatedAt' => time(),
]);
Обновить несколько записей
Article::update(
  ['category' => $category],
  ['enabled' => false]
);

fetchOneAndUpdate()

Сигнатура
public static function fetchOneAndUpdate(
  array|string|int $cond = [],
  array $sort = [],
  array $data = []
): static|null

Находит одну запись, обновляет её и возвращает обновлённую модель. В текущем ядре этот метод реализован в MongoDB driver-е через findAndModify.

Атомарно обновить и получить запись
$article = Article::fetchOneAndUpdate(
  ['url' => 'about-us'],
  [],
  [
    'title' => 'About company',
    'updatedAt' => time(),
  ]
);

populate()

Сигнатура
public function populate(array $data, bool $fromSet = true): void

Заполняет объект модели данными из массива. Неизвестные поля игнорируются. Значения известных полей приводятся к типам из metadata.

Заполнить модель из массива
$article = new Article();
$article->populate([
  'title' => 'About us',
  'views' => '100',
  'enabled' => '1',
]);

save()

Сигнатура
public function save(): int

Сохраняет объект модели. Если primary value отсутствует — создаёт новую запись. Если primary value уже есть — обновляет существующую запись. Для createdAt/updatedAt применяются conventions driver-а.

Создать через объект
$article = new Article();
$article->title = 'Новая статья';
$article->url = 'new-article';
$article->enabled = true;
$article->save();
Обновить через объект
$article = Article::one('new-article');
$article->title = 'Обновлённая статья';
$article->save();

Методы удаления данных

Эти методы физически удаляют записи из базы. Для soft-delete обычно используют поле enabled.

remove()

Сигнатура
public function remove(): void

Удаляет текущую модель. Если у объекта есть primary value, driver удалит соответствующую запись.

Удалить объект
$article = Article::one('old-article');

if ($article) {
  $article->remove();
}

batchRemove()

Сигнатура
public static function batchRemove(
  array|string|int $cond = [],
  ?int $limit = null
): int

Удаляет записи по условию и возвращает количество удалённых записей. Внутри вызывает driver method remove().

Удалить отключённые записи
$removed = Article::batchRemove([
  'enabled' => false,
]);
Удалить одну запись по id
$removed = Article::batchRemove($articleId, 1);

Служебные методы

Эти методы помогают получить данные объекта, metadata или изменить поведение driver-а.

toArray()

Сигнатура
public function toArray(): array

Преобразует модель в массив. Model references и typed objects также преобразуются в массивы.

API response
$article = Article::one('about-us');

return $article?->toArray();

getData()

Сигнатура
public function getData(): array

Возвращает внутренние данные документа без полного API-преобразования через toArray(). Полезно для диагностики и низкоуровневой работы.

Raw data
$article = Article::one('about-us');
$data = $article->getData();

meta() / getMeta()

Сигнатура
public static function meta(): Air\Model\Meta

public function getMeta(): Air\Model\Meta

Возвращает metadata модели: collection, primary, список свойств, типы, enum, признаки model reference и typed object.

Metadata
$collection = Article::meta()->getCollection();
$primary = Article::meta()->getPrimary();

$article = new Article();
$hasUrl = $article->getMeta()->hasProperty('url');

addCond()

Сигнатура
public static function addCond(array|string|int $cond = []): array

Преобразует scalar condition в condition по primary и добавляет automatic filters enabled и language, если такие поля есть в модели и не были указаны явно.

Проверить итоговое условие
$cond = Article::addCond('about-us');

// Например:
// [
//   'id' => 'about-us',
//   'enabled' => true,
// ]

addPosition()

Сигнатура
public static function addPosition(array $sort = []): array

Добавляет сортировку по position ASC, если у модели есть поле position и сортировка не была передана явно.

Default sort
$sort = MenuItem::addPosition([]);

// ['position' => 1]

setDriver()

Сигнатура
public static function setDriver(Air\Model\Driver\DriverAbstract $class): void

Позволяет временно заменить driver class для моделей. Обычно нужен для тестов, специальных миграций или нестандартных окружений.

Custom driver
Article::setDriver(new CustomDriver($config));

reflectSchema()

Сигнатура
public static function reflectSchema(): void

Просит driver синхронизировать схему модели с базой. В MySQL driver-е метод создаёт/изменяет таблицу по metadata модели. В MongoDB driver-е сейчас фактически пустой.

Schema reflection
Article::reflectSchema();
Category::reflectSchema();
