Input factory

Air\Form\Input — удобная фабрика, которая создаёт элементы формы по имени метода: Input::text(), Input::email(), Input::model() и т.д.

Как работает Input

Фабрика использует magic method __callStatic(). Имя метода превращается в класс элемента из namespace Air\Form\Element. Например, Input::textarea('description') создаёт Air\Form\Element\Textarea.

Factory usage
<?php

use Air\Form\Input;

$title = Input::text('title');
$description = Input::textarea('description');
$enabled = Input::checkbox('enabled', allowNull: true);

Автоматический label

Если label не передан явно, AirCMS строит его из имени поля. Например, metaTitle превращается в Meta title. Для некоторых окончаний есть специальные правила: title, description, subTitle.

Label
<?php

Input::text('title');
Input::text('metaTitle');
Input::text('shortDescription');

Input::text('title', label: 'Заголовок страницы');

Специальные shortcut-методы

Некоторые методы фабрики не имеют отдельного класса, а создают Text с дополнительными настройками.

МетодЧто создаётЧто добавляет
Input::number()Texttype = number
Input::safe()TextTrim, HtmlSpecialChars, StripTags
Input::password()TextTrim + StringLength 6..255
Input::phone()TextPhone filter + Phone validator
Input::email()TextEmail filter + Email validator
Shortcut methods
<?php

use Air\Form\Input;

$price = Input::number('price');
$email = Input::email('email');
$phone = Input::phone('phone');
$password = Input::password('password');
$safeTitle = Input::safe('title');

Named arguments

Все опции элемента можно передавать как named arguments. Это самый читаемый способ описывать формы.

Named arguments
<?php

use Air\Form\Input;
use Air\Filter\Trim;
use Air\Validator\Regex;

Input::text(
  'url',
  label: 'URL',
  hint: 'Только латиница, цифры и дефисы',
  allowNull: false,
  filters: [Trim::class],
  validators: [
    Regex::class => [
      'pattern' => '/^[a-z0-9-]+$/',
      'message' => 'URL может содержать только a-z, 0-9 и дефис',
    ],
  ],
);
