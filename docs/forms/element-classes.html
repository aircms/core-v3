Классы элементов

Любой элемент можно создать напрямую через класс из Air\Form\Element. Это полезно, когда нужно явно контролировать тип класса или расширять встроенный элемент.

Общий конструктор элемента

Все элементы принимают имя поля и массив опций. Опции применяются через setter-методы: label → setLabel(), validators → setValidators(), filters → setFilters().

Создание элемента напрямую
<?php

use Air\Form\Element\Text;
use Air\Filter\Trim;
use Air\Validator\StringLength;

$title = new Text('title', [
  'label' => 'Название',
  'placeholder' => 'Введите название',
  'filters' => [Trim::class],
  'validators' => [
    StringLength::class => [
      'min' => 3,
      'max' => 120,
      'message' => 'Название должно быть от 3 до 120 символов',
    ],
  ],
]);

Text, Textarea, Tiny

Text — универсальное строковое поле. Textarea нужен для длинного текста в UI/Admin. Tiny используется как визуальный HTML-редактор.

Строковые элементы
<?php

use Air\Form\Element\Text;
use Air\Form\Element\Textarea;
use Air\Form\Element\Tiny;

$title = new Text('title', [
  'label' => 'Название',
]);

$description = new Textarea('description', [
  'label' => 'Описание',
  'allowNull' => true,
]);

$content = new Tiny('content', [
  'label' => 'Контент',
  'allowNull' => true,
]);

Model, SingleModel, MultipleModel

Эти элементы работают со связанными моделями. В опции model передаётся class name модели, а field определяет, какое поле использовать как label в UI.

Связи с моделями
<?php

use Air\Form\Element\SingleModel;
use Air\Form\Element\MultipleModel;
use App\Model\Category;
use App\Model\Tag;

$category = new SingleModel('category', [
  'model' => Category::class,
  'field' => 'title',
]);

$tags = new MultipleModel('tags', [
  'model' => Tag::class,
  'field' => ['title'],
  'allowNull' => true,
]);

Group и MultipleGroup

Group описывает один вложенный объект. MultipleGroup описывает массив таких объектов.

Вложенные структуры
<?php

use Air\Form\Element\Group;
use Air\Form\Element\MultipleGroup;
use Air\Form\Input;

$contact = new Group('contact', [
  'elements' => [
    Input::text('name'),
    Input::email('email', allowNull: true),
    Input::phone('phone', allowNull: true),
  ],
]);

$contacts = new MultipleGroup('contacts', [
  'elements' => [
    Input::text('name'),
    Input::email('email', allowNull: true),
  ],
  'allowNull' => true,
]);

Собственный элемент

Если нужен особый сценарий, можно создать класс элемента, наследоваться от существующего элемента и переопределить getValue(), getCleanValue(), isValid() или template.

Custom element
<?php

namespace App\Form\Element;

use Air\Form\Element\Text;

class Slug extends Text
{
  public function getValue(): mixed
  {
    return strtolower(trim((string)parent::getValue()));
  }
}
