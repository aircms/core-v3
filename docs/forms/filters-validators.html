Validators & Filters

Валидаторы проверяют значение, а фильтры изменяют его после успешной валидации. В AirCMS они подключаются прямо к элементам формы.

Встроенные валидаторы

КлассНазначениеОсновные опции
Air\Validator\EmailПроверяет email.allowNull, errorMessage
Air\Validator\PhoneПроверяет телефон.allowNull, errorMessage
Air\Validator\NumberПроверяет числовой диапазон.min, max
Air\Validator\StringLengthПроверяет длину строки.min, max, exact, encoding
Air\Validator\RegexПроверяет значение регулярным выражением.pattern
Air\Validator\ContainПроверяет, что значение входит в список.list

Как использовать валидаторы

Validators in elements
<?php

use Air\Form\Input;
use Air\Validator\StringLength;
use Air\Validator\Regex;
use Air\Validator\Contain;

$elements = [
  Input::text('title', validators: [
    StringLength::class => [
      'min' => 3,
      'max' => 120,
      'message' => 'Название должно быть от 3 до 120 символов',
    ],
  ]),
  Input::text('url', validators: [
    Regex::class => [
      'pattern' => '/^[a-z0-9-]+$/',
      'message' => 'Некорректный URL',
    ],
  ]),
  Input::select('type', options: [
    'article' => 'Article',
    'page' => 'Page',
  ], validators: [
    Contain::class => [
      'list' => ['article', 'page'],
      'message' => 'Неизвестный тип',
    ],
  ]),
];
Validator вне формы
<?php

use Air\Validator\Email;

$validator = Email::valid(
  errorMessage: 'Введите корректный email',
  allowNull: false,
);

if (!$validator->isValid('wrong-email')) {
  $message = $validator->getErrorMessage();
}

Custom validation

Если validator class не найден, AirCMS умеет обработать callable. Callable должен вернуть true или текст ошибки.

Callable validator
<?php

use Air\Form\Input;

Input::text('slug', validators: [
  function ($value) {
    if (str_contains((string)$value, 'admin')) {
      return 'Slug не должен содержать слово admin';
    }

    return true;
  },
]);

Встроенные фильтры

КлассЧто делает
Air\Filter\TrimОбрезает пробелы по краям.
Air\Filter\LowercaseПриводит строку к нижнему регистру.
Air\Filter\UppercaseПриводит строку к верхнему регистру.
Air\Filter\EmailНормализует email.
Air\Filter\PhoneНормализует телефон.
Air\Filter\NumberПриводит значение к числу.
Air\Filter\StripTagsУдаляет HTML-теги.
Air\Filter\HtmlSpecialCharsЭкранирует HTML-символы.
Air\Filter\SafeБезопасная обработка строки.

Как использовать фильтры

Filters in elements
<?php

use Air\Form\Input;
use Air\Filter\Trim;
use Air\Filter\Lowercase;
use Air\Filter\StripTags;

Input::text('email', filters: [
  Trim::class,
  Lowercase::class,
]);

Input::text('title', filters: [
  Trim::class,
  StripTags::class,
]);
Filter вне формы
<?php

use Air\Filter\Trim;

$filter = new Trim();
$value = $filter->filter('  Hello  ');

// Hello
