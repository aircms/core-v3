Элементы формы

Элемент формы в AirCMS отвечает за одно поле: хранит значение, умеет валидировать, фильтровать, возвращать очищенное значение и, при необходимости, отрисовываться в UI/Admin.

Общие опции элементов

Все элементы наследуются от Air\Form\Element\ElementAbstract и создаются по общей схеме: имя поля + массив опций. Через Input те же опции передаются named arguments.

Общие опции
<?php

use Air\Form\Input;
use Air\Filter\Trim;
use Air\Validator\StringLength;

Input::text(
  'title',
  label: 'Название',
  description: 'Короткое название записи',
  hint: 'Будет видно в списке',
  placeholder: 'Введите название',
  value: 'Default title',
  allowNull: false,
  filters: [Trim::class],
  validators: [
    StringLength::class => [
      'min' => 3,
      'max' => 120,
      'message' => 'Название должно быть от 3 до 120 символов',
    ],
  ],
);

API и Admin: один Form, разные цели

В API форма чаще всего нужна только как схема валидации. Элемент не рисуется, поэтому можно выбирать более простой элемент, если он достаточно хорошо валидирует входные данные. В Admin/UI элемент ещё и отрисовывается, поэтому там важно выбрать удобный визуальный контрол.

СценарийВ APIВ Admin/UIПочему
Длинный plain textInput::text('description')Input::textarea('description')В API нет textarea как UI-контрола, важна только строка. В админке textarea удобнее.
HTML-контентInput::text('content') или custom validationInput::tiny('content')Tiny нужен для редактора. В API обычно приходит готовая строка/HTML.
Rich content blocksInput::richContent('content')Input::richContent('content')Структурный элемент полезен и для API, и для админки.
ФайлInput::text('image') для URL/id или custom validationInput::storage('image')Storage рисует файловый интерфейс. В API часто передают уже загруженный файл/URL.
Связанная модельInput::model('category', model: Category::class)Input::singleModel('category', model: Category::class)В API удобно сразу получить model object. В админке нужен select/autocomplete.
Массив строкInput::multipleText('tags')Input::multipleText('tags')Одинаково полезно: API валидирует массив, Admin рисует список.

Примеры элементов

Набор элементов
<?php

use Air\Form\Input;
use App\Model\Category;

$elements = [
  Input::text('title'),
  Input::textarea('description'),
  Input::checkbox('enabled', allowNull: true),
  Input::select('type', options: [
    'article' => 'Article',
    'page' => 'Page',
  ]),
  Input::singleModel('category', model: Category::class),
  Input::multipleText('tags', allowNull: true),
];
