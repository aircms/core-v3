Built-in Type Objects

File

Объект файла из storage: URL, thumbnail, размеры, mime, модификации изображений и удаление.

File

Air\Type\File описывает файл, который уже находится в storage-сервисе AirCMS. Все файловые поля в админке и моделях работают именно через этот объект.

Файловые поля в модели
/**
 * @property Air\Type\File $image
 * @property Air\Type\File[] $gallery
 */
class Article extends Air\Model\ModelAbstract
{
}

getSrc()

Сигнатура
public function getSrc(?int $width = null, ?int $height = null, ?int $quality = null, ?string $format = null): string

Возвращает URL файла. Если передать width, height, quality или format, будет построен URL модифицированной версии. Storage-сервис физически создаёт такой файл при запросе.

Размеры и формат
$src = $article->image->getSrc();
$webp = $article->image->getSrc(1200, null, 85, Air\Type\File::WEBP);
$thumb = $article->image->getSrc(400, 300, 80, Air\Type\File::WEBP);

getThumbnail()

Сигнатура
public function getThumbnail(): string

Возвращает URL thumbnail. Особенно полезно для видео, PDF и файлов, у которых есть отдельная превью-картинка.

Thumbnail в API
return [
  'src' => $file->getSrc(),
  'thumbnail' => $file->getThumbnail(),
];

getSize(), getMime(), getDims()

Сигнатура
public function getSize(): int
public function getMime(): string
public function getDims(): array

Методы для вывода информации о файле и проверки типа.

Размеры изображения
if ($file->isImage()) {
  $dims = $file->getDims();

  return [
    'width' => $dims['width'],
    'height' => $dims['height'],
  ];
}

getFilename(), getSrcContent(), getBase64Content()

Сигнатура
public function getFilename(): string
public function getSrcContent(): string|false
public function getBase64Content(): string

Используются для интеграций: вложения писем, external API, генерация base64-preview.

Base64 для внешнего API
$attachment = [
  'filename' => $file->getFilename(),
  'content' => $file->getBase64Content(),
];

isImage(), remove(), fromArray()

Сигнатура
public function isImage(): bool
public function remove(): bool
public static function fromArray(?array $file): self

isImage() проверяет mime. remove() удаляет файл или папку через Air\Storage. fromArray() восстанавливает объект из массива.

Восстановление из массива
$file = Air\Type\File::fromArray($rawFile);

if ($file->isImage()) {
  echo $file->getSrc(800, null, 85, Air\Type\File::WEBP);
}
