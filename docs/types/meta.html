Built-in Type Objects

Meta

SEO meta object для моделей и UI: computed data, Open Graph, вывод в layout и использование в формах.

Meta

Air\Type\Meta хранит SEO-данные страницы: title, description, keywords, Open Graph title/description/image. Его удобно использовать в UI-моделях: страницы, статьи, категории, проекты.

Meta в модели
use Air\Model\ModelAbstract;
use Air\Type\Meta;

/**
 * @collection Page
 *
 * @property string $id
 * @property string $url
 * @property string $title
 * @property string $description
 * @property Meta $meta
 */
class Page extends ModelAbstract
{
}

dummy()

Сигнатура
public static function dummy(array $data = []): static

Создаёт meta-object. Если данные пустые, включает useModelData, чтобы meta могла брать title/description/image из модели.

Meta по данным модели
$page->meta = Air\Type\Meta::dummy();
$page->save();

getComputedData()

Сигнатура
public function getComputedData(): array

Возвращает итоговые meta-данные. Если включён useModelData, данные берутся из связанной модели.

Meta для API
$meta = $page->meta->getComputedData();

return [
  'title' => $meta['title'],
  'description' => $meta['description'],
  'ogImage' => $meta['ogImage']?->getSrc(),
];

__toString()

Сигнатура
public function __toString(): string

Возвращает готовые HTML meta tags. Это удобно для UI layout.

Использование Meta в UI layout
<?php

$page = App\Model\Page::one([
  'url' => $this->getRouter()->getUrlParams()['page'] ?? 'home',
]);

?>
<!doctype html>
<html lang="ru">
<head>
  <?php echo $page->meta; ?>
</head>
<body>
  <h1><?php echo $page->title; ?></h1>
</body>
</html>

getObjectData()

Сигнатура
public function getObjectData(): array

Берёт title, description и image из модели, если meta связана с объектом. Метод смотрит на поля title, subTitle, description, content, richContent, image, images.

Данные из модели
$meta = new Air\Type\Meta([], $article);
$data = $meta->getObjectData();

Meta в админке и UI

В админке поле Meta обычно редактируется как отдельный блок SEO. В UI можно либо вывести meta; ?>, либо взять getComputedData() и построить теги вручную.

Форма с Meta
use Air\Form\Input;
use Air\Form\Form;

class PageForm extends Form
{
  public function __construct()
  {
    parent::__construct(elements: [
      Input::text('title'),
      Input::textarea('description'),
      Input::meta('meta'),
    ]);
  }
}
