Built-in Type Objects

Quote, Social, FaIcon

Небольшие встроенные type objects для цитат, социальных ссылок и Font Awesome иконок.

Quote

Air\Type\Quote хранит цитату и автора. Чаще всего используется внутри RichContent или блоков отзывов.

Quote methods

Сигнатура
public function getAuthor(): string
public function setAuthor(string $author): void
public function getQuote(): string
public function setQuote(string $quote): void
Quote в API
$quote = new Air\Type\Quote([
  'author' => 'Client',
  'quote' => 'Great service!',
]);

return [
  'author' => $quote->getAuthor(),
  'quote' => $quote->getQuote(),
];

Social

Air\Type\Social хранит тип социальной сети и ссылку. Поддерживаемые типы можно получить через Social::getTypes().

Social methods

Сигнатура
public static function getTypes(): array
public function getType(): ?string
public function setType(?string $type): void
public function getLink(): ?string
public function setLink(?string $link): void
Social link
$social = new Air\Type\Social([
  'type' => Air\Type\Social::TYPE_INSTAGRAM,
  'link' => 'https://instagram.com/example',
]);

return [
  'type' => $social->getType(),
  'link' => $social->getLink(),
];

FaIcon

Air\Type\FaIcon хранит Font Awesome icon и style. В админке он полезен для меню, карточек и визуальных бейджей.

FaIcon methods

Сигнатура
public function getIcon(): ?string
public function setIcon(?string $icon): void
public function getStyle(): string
public function setStyle(string $style): void
public static function getIcons(): array
public function isBrand(): bool
public static function icon(string|array $iconData): self
FaIcon для UI
$icon = Air\Type\FaIcon::icon([
  'icon' => Air\Type\FaIcon::ICON_FILE_LINES,
  'style' => Air\Type\FaIcon::STYLE_SOLID,
]);

return [
  'class' => $icon->getStyle() . ' fa-' . $icon->getIcon(),
  'brand' => $icon->isBrand(),
];
