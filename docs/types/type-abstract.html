Built-in Type Objects

TypeAbstract

Базовый механизм вложенных typed objects: заполнение из массива, преобразование типов, toArray и toRaw.

TypeAbstract

Air\Type\TypeAbstract — базовый класс для всех type objects. Он отвечает за заполнение объекта из массива, преобразование вложенных объектов, ссылки на модели, toArray() и toRaw().

Конструктор

Сигнатура
public function __construct(?array $data = [])

Заполняет публичные свойства объекта по ключам массива. Если свойство типизировано другим type object или моделью, AirCMS пытается преобразовать значение в нужный объект.

Свой type object
<?php

namespace App\Type;

use Air\Type\TypeAbstract;

class Address extends TypeAbstract
{
  public ?string $city = null;
  public ?string $street = null;
  public ?string $zip = null;
}

$address = new Address([
  'city' => 'Bucharest',
  'street' => 'Main street',
  'zip' => '010001',
]);

getPropertyType()

Сигнатура
public function getPropertyType(string $property): ?array

Возвращает тип свойства и признак массива. Для массивов сложных объектов используется PHPDoc @var SomeType[].

Определение типа свойства
use Air\Type\TypeAbstract;

class Gallery extends TypeAbstract
{
  /**
   * @var Air\Type\File[]
   */
  public array $images = [];
}

$gallery = new Gallery();
[$type, $isArray] = $gallery->getPropertyType('images');

toArray()

Сигнатура
public function toArray(): array

Преобразует объект в обычный массив для API или debug. Вложенные объекты, у которых есть toArray(), тоже преобразуются.

API-массив
$address = new Address([
  'city' => 'Bucharest',
  'street' => 'Main street',
]);

return $address->toArray();

toRaw()

Сигнатура
public function toRaw(): array

Преобразует объект в формат для хранения. Если внутри есть модель, в raw будет записан primary value модели. Если внутри есть другой type object, будет вызван его toRaw().

Raw-формат для хранения
class PromoBlock extends TypeAbstract
{
  public ?App\Model\Category $category = null;
  public ?Address $address = null;
}

$raw = $promoBlock->toRaw();

Вложенные объекты и массивы

Для массива type objects обязательно указывай PHPDoc @var Type[], иначе PHP не знает тип элементов массива.

Массив вложенных type objects
<?php

namespace App\Type;

use Air\Type\TypeAbstract;

class Slide extends TypeAbstract
{
  public ?string $title = null;
  public ?string $description = null;
}

class Slider extends TypeAbstract
{
  /**
   * @var Slide[]
   */
  public array $slides = [];
}

$slider = new Slider([
  'slides' => [
    ['title' => 'First'],
    ['title' => 'Second'],
  ],
]);
