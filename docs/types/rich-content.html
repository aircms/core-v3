Built-in Type Objects

RichContent

Блоки контента разных типов: text, html, file, files, embed и quote, а также рендер в UI/API.

RichContent

Air\Type\RichContent хранит один блок контента. Массив таких блоков можно использовать для статей, страниц, лендингов и описаний, где контент состоит из разных типов.

RichContent[] в модели
/**
 * @property Air\Type\RichContent[] $richContent
 */
class Article extends Air\Model\ModelAbstract
{
}

Типы RichContent

В классе есть такие типы: file, files, quote, text, html, embed. Метод getAllTypes() по умолчанию возвращает file, files, text, html, embed. quote можно добавить через конфигурацию админки.

Разрешённые типы в админке
admin: fn() => Config::admin(
  domain: 'admin.*',
  richContent: [
    Air\Type\RichContent::TYPE_TEXT,
    Air\Type\RichContent::TYPE_HTML,
    Air\Type\RichContent::TYPE_FILE,
    Air\Type\RichContent::TYPE_FILES,
    Air\Type\RichContent::TYPE_EMBED,
    Air\Type\RichContent::TYPE_QUOTE,
  ]
)

__construct()

Сигнатура
public function __construct(?array $data = null)

Создаёт блок нужного типа и преобразует value: file → File, files → массив File, quote → Quote, text/html/embed → строка.

Создание блока
$block = new Air\Type\RichContent([
  'type' => Air\Type\RichContent::TYPE_TEXT,
  'value' => 'Hello world',
]);

getType() и getValue()

Сигнатура
public function getType(): string
public function getValue(): mixed

Используются для рендера блоков в UI или API.

Рендер в UI
foreach ($article->richContent as $block) {
  if ($block->getType() === Air\Type\RichContent::TYPE_HTML) {
    echo $block->getValue();
  }

  if ($block->getType() === Air\Type\RichContent::TYPE_FILE) {
    echo '<img src="' . $block->getValue()->getSrc(1200) . '">';
  }
}

toArray() и getAllTypes()

Сигнатура
public function toArray(): array
public static function getAllTypes(): array

toArray() удобен для API. getAllTypes() возвращает default-набор типов.

RichContent в API
return array_map(
  fn(Air\Type\RichContent $block) => $block->toArray(),
  $article->richContent ?? []
);
