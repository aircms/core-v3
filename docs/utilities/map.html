Map

Air\Map — это утилита для преобразования моделей, typed objects, cursor-ов и обычных массивов в API-friendly структуры.

Основные методы Форматы mapper-а

Что делает Map

В AirCMS Map обычно используется в API-слое. Контроллер получает модель или коллекцию моделей, а Map превращает эти данные в массив, который безопасно вернуть наружу.

Идея простая: не отдавать модель целиком, а явно описать, какие поля нужны клиенту и как именно их нужно преобразовать.

<?php

use Air\Map;
use App\Model\Article;

public function details(Article $article): array
{
  return Map::single($article, [
    'id',
    'url',
    'title',
    'image' => fn(Article $article) => $article->image?->getSrc(),
  ]);
}
Главная польза: controller остаётся коротким, а структура API-ответа описывается отдельно и предсказуемо.

Три основных метода

В реальной работе чаще всего используются три метода: execute(), single() и multiple().

Map::execute()

execute() — универсальный метод. Он принимает любые входные данные и сам выбирает способ обработки:

  • если mapper — массив, вызывается логика ассоциативного маппинга;
  • если mapper — строка, возвращается значение одного поля;
  • если mapper — функция, она применяется к одному элементу или к каждому элементу коллекции;
  • если входные данные — cursor или список, результат будет массивом результатов;
  • если входные данные — одна модель, typed object или один ассоциативный массив, результат будет одним значением или одним массивом.
Сигнатура
public static function execute(mixed $data, mixed $mapper, array $userData = []): mixed

Пример: execute сам понимает, что передана одна модель

<?php

$article = Article::one($id);

return Map::execute($article, [
  'id',
  'title',
  'url',
]);

Пример: execute сам понимает, что передан cursor

<?php

$articles = Article::all(['enabled' => true]);

return Map::execute($articles, [
  'id',
  'title',
  'url',
]);

Map::single()

single() используется, когда ты заранее знаешь, что маппишь один объект: одну модель, один typed object или один ассоциативный массив.

Под капотом single() просто вызывает execute(), но в коде он лучше показывает намерение: здесь ожидается один объект.

Сигнатура
public static function single(mixed $data, mixed $mapper, array $userData = []): mixed

Пример: одна модель

<?php

return Map::single($article, [
  'id',
  'title',
  'image' => fn(Article $article) => $article->image?->getSrc(),
]);

Пример: получить одно поле из одной модели

<?php

$title = Map::single($article, 'title');

Map::multiple()

multiple() используется, когда ожидается список: cursor, массив моделей или массив ассоциативных массивов.

Он тоже вызывает execute(), но гарантированно возвращает массив. После маппинга результат очищается от пустых значений и переиндексируется через array_values().

Сигнатура
public static function multiple(mixed $data, mixed $mapper, array $userData = []): array

Пример: список моделей

<?php

return Map::multiple(Article::all(['enabled' => true]), [
  'id',
  'title',
  'url',
]);

Пример: получить только список id

<?php

$ids = Map::multiple(Article::all(['enabled' => true]), 'id');

Как Map определяет single или multiple

Map не угадывает случайно. Он проверяет тип входных данных.

Что передано Как обрабатывается Что вернётся
ModelInterface / ModelAbstract Одна запись Один массив или одно значение
TypeAbstract Один typed object Один массив или одно значение
Cursor Коллекция Массив результатов
Массив с индексом 0 Коллекция Массив результатов
Ассоциативный массив Одна запись Один массив или одно значение

Каким может быть mapper

Второй аргумент Map может быть строкой, функцией или массивом. Это самая важная часть, потому что именно mapper описывает результат.

Mapper как строка

Если mapper — строка, Map возвращает значение одного поля.

Для одной модели вернётся одно значение. Для cursor-а или массива моделей вернётся массив значений.

<?php

$title = Map::single($article, 'title');

$ids = Map::multiple(Article::all(), 'id');

Результат для списка id

[
  '661f0f2e7c8a9b0011223344',
  '661f0f2e7c8a9b0011223355',
  '661f0f2e7c8a9b0011223366',
]

Mapper как функция

Если mapper — функция, она вызывается для одного объекта или для каждого объекта списка.

Функция получает три аргумента: текущий элемент, пользовательские данные и индекс элемента.

Формат callback-а
fn(mixed $item, array $userData = [], int $index = 0): mixed

Пример: одна модель

<?php

return Map::single($article, function (Article $article) {
  return $article->title . ' / ' . $article->url;
});

Пример: список моделей

<?php

return Map::multiple(Article::all(), function (Article $article) {
  return [
    'label' => $article->title,
    'value' => $article->id,
  ];
});

Пример: использовать индекс

<?php

return Map::multiple(Article::all(), function (Article $article, array $userData, int $index) {
  return [
    'number' => $index + 1,
    'title' => $article->title,
  ];
});

Mapper как массив строк

Самый частый вариант — массив строк. Каждая строка считается именем поля, которое нужно взять из модели, typed object или массива.

<?php

return Map::single($article, [
  'id',
  'url',
  'title',
]);

Результат

[
  'id' => '661f0f2e7c8a9b0011223344',
  'url' => 'hello-world',
  'title' => 'Hello world',
]

Mapper как ассоциативный массив

Если ключ массива — строка, то ключ становится именем поля в результате.

Значение может быть строкой или функцией.

<?php

return Map::single($article, [
  'id',
  'headline' => 'title',
  'image' => fn(Article $article) => $article->image?->getSrc(),
]);

Результат

[
  'id' => '661f0f2e7c8a9b0011223344',
  'headline' => 'Hello world',
  'image' => 'https://cdn.example.com/articles/hello.jpg',
]

Как достаются значения

При обработке массива mapper-а Map проходит по каждому элементу и вызывает внутреннее преобразование.

Mapper Ключ результата Значение результата
'title' title $data->title или $data['title']
'headline' => 'title' headline $data->title или $data['title']
'image' => fn(...) => ... image то, что вернула функция

Если данные — модель, Map проверяет поле через metadata модели. Если поле есть в модели, берётся оно. Если поле не найдено, возвращается null.

Если данные — обычный массив, значение берётся по ключу mapper-а или по ключу результата.

Третий аргумент: userData

Третий аргумент нужен, когда mapper-функции требуется внешний контекст: язык, текущий пользователь, настройки, валюта, host CDN и т.д.

<?php

return Map::single($article, [
  'id',
  'title',
  'canEdit' => function (Article $article, array $userData) {
    return $userData['user']->role === 'admin';
  },
], [
  'user' => $this->user,
]);

В callback-е $userData всегда приходит вторым аргументом.

Вложенные maps

Внутри callback-а можно вызывать Map повторно. Так удобно отдавать связанные модели и typed objects.

<?php

return Map::single($article, [
  'id',
  'title',
  'category' => fn(Article $article) => Map::single($article->category, [
    'id',
    'title',
    'url',
  ]),
  'tags' => fn(Article $article) => Map::multiple($article->tags ?? [], [
    'id',
    'title',
  ]),
]);
Важно: если связанная модель может быть null, callback должен это учитывать. Map::single(null, ...) вернёт null.

Практический API-паттерн

В больших проектах удобнее держать mapper-ы в отдельных классах.

<?php

namespace App\Module\Api\Map;

use Air\Map;
use App\Model\Article;

class ArticleMap
{
  public static function preview(): array
  {
    return [
      'id',
      'url',
      'title',
      'image' => fn(Article $article) => $article->image?->getThumbnail(),
    ];
  }

  public static function full(): array
  {
    return [
      ...self::preview(),
      'description',
      'content',
      'category' => fn(Article $article) => Map::single($article->category, [
        'id',
        'title',
        'url',
      ]),
    ];
  }
}

Использование в controller-е

<?php

use Air\Map;
use App\Model\Article;
use App\Module\Api\Map\ArticleMap;

class Articles extends Base
{
  public function index(): array
  {
    return Map::multiple(
      Article::all(['enabled' => true], ['position' => 1]),
      ArticleMap::preview()
    );
  }

  public function details(Article $article): array
  {
    return Map::single($article, ArticleMap::full());
  }
}

Map::adjust()

adjust() — вспомогательный метод. Он сначала пытается взять все известные поля из данных, а затем применяет переданный mapper поверх них.

Это удобно для debug, быстрых internal API или временных admin-preview, но для публичного API лучше явно перечислять поля через single(), multiple() или execute().

Сигнатура
public static function adjust(mixed $data, array $mapper, array $userData = []): mixed

Пример

<?php

return Map::adjust($article, [
  'image' => fn(Article $article) => $article->image?->getSrc(),
]);

Рекомендации

Когда использовать single()

Когда controller работает с одной моделью: details page, profile, settings, one API resource.

Когда использовать multiple()

Когда controller отдаёт список: каталог, новости, пользователи, заказы, результаты поиска.

Когда использовать execute()

Когда вход может быть и одиночным объектом, и коллекцией, или когда ты строишь универсальный helper.

Когда использовать строковый mapper

Когда нужно быстро получить одно поле или список значений одного поля, например массив id.
