Slug

Air\Slug генерирует URL-safe slug из строки с транслитерацией.

Методы

slug

Преобразует строку в slug. Поддерживает delimiter, limit, lowercase, replacements и transliterate.

Сигнатура
public static function slug(string $str, array $options = []): string

Создать URL для модели

<?php

$article->url = Slug::slug($article->title);
$article->save();

Свой delimiter

<?php

$url = Slug::slug('Hello World', [
  'delimiter' => '_',
]);

Ограничить длину

<?php

$url = Slug::slug($title, [
  'limit' => 80,
]);

Когда использовать

  • поле url у моделей;
  • SEO-friendly адреса;
  • имена файлов;
  • нормализация пользовательских названий.
