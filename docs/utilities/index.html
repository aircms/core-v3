Utilities

В AirCMS есть набор небольших utility-классов, которые закрывают типовые задачи проекта: преобразование данных, HTTP-запросы, работа с cookie, шифрование, CSV, DOM-парсинг, sitemap, slug, guard-проверки и другие операции.

Когда использовать utilities

Utilities лучше использовать там, где задача не является бизнес-логикой конкретной модели или сервиса. Например: подготовить API-ответ, сделать внешний HTTP-запрос, распарсить HTML, сгенерировать slug, проверить пароль или собрать sitemap.

Практическое правило: controller должен оставаться коротким. Если нужна техническая операция — используй utility. Если нужна бизнес-логика — выноси её в service.
